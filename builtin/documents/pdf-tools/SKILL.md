# PDF 文档处理

根据任务选择文字提取、页面操作、表单填写或新文档生成。先检查输入路径、页数、加密状态和可读取程度。本文由 macs 项目独立编写；外部软件的安装与使用继续适用其各自许可。

## 阅读和提取

通过 `tool_detail` 发现 `extract` 的实际参数，优先使用内置 PDF 提取能力。核对相关完整页面中的正文、表格、单位、脚注和来源；文字提取结果不能单独说明页面布局。

扫描件没有可选文字时，检查本机 OCR 能力，按需识别并抽查原图。表格提取后核对列、合并格、数字和单位，避免将视觉上的一行错配到另一记录。受密码保护时向用户索取合法打开方式，不猜测可读结果。

## 页面与文档操作

先查询现有 `convert`、`extract` 和文档生成工具支持的行为。需要程序化处理时，可使用已安装的 `pypdf` 完成页面选择、合并、旋转及元数据维护；新建报告可使用支持中文字体的 PDF 生成库。参数和 API 按本机库版本核对。

输出使用新路径，保留原件。不要在目标文件尚未打开和验收前删除输入。检查拆分范围采用的页码基准，确认最终页数和顺序。删除文字或隐藏图层不自动构成有效脱敏；脱敏后需要同时检查可提取文本、批注、元数据和页面图像。

## 表单

先列出规范字段树和页面 Widget，核对字段名、类型、当前值及可选值。填写后重新读取字段值与 Widget 的继承值，并检查可见外观；仅设置刷新标志不能证明文件已正确填写。

有签名的文件不能在未说明后果时重写或扁平化。默认保留可编辑表单，只有用户明确需要静态版本时才扁平化，并检查最终 Widget 与字段树是否按预期处理。

## 页面检查

使用本机可用的 PDF 渲染器逐页检查最终输出，确认无裁切、重叠、缺字及模糊表格。字体和图片须具有相应使用许可。没有渲染能力时说明结构检查的范围，不把文字提取成功表述为完整视觉验收。

对外报告引用应指向真实文档或官方来源，使用用户能够识别的标题和页码。交付前重新打开文件，确认路径、页数及用户要求的内容。
