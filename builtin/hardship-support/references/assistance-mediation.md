# 生活救助、邻里与一般人际协调

## 生活困难与救助导航

先确认今天和未来七天是否缺少安全住所、食物、必要医疗、照护、基本水电、通勤、证件、工作收入，或儿童、老人、残障人士的基本保障。用户没有提及并不代表已经安全；把这些列为简短待确认项，不要擅自写成“基本生活可维持”或反向断言存在危机。

若有即时危险或基本生活中断，先给一个立刻可做的安全动作、可信任联系人或本地紧急支持路径，再处理长期申请。普通困难不要过度危机化。

根据所在地、家庭结构、收入资产、困难原因和已有身份，检索民政、人社、医保、教育、住建、残联、工会、社区或村委及政务服务的当前官方渠道。对每项可能资源说明：

- 适用地区和对象；
- 核心条件及仍需核实的条件；
- 所需材料和正式入口；
- 受理层级、办理步骤和当前公布时限；
- 补正、状态查询、复核或替代路径；
- 官方页面日期和本次检索日期。

不要假设用户一定符合低保、临时救助、医疗救助、住房、就业、助学、残障或慈善资源。可以起草困难说明、家庭情况表、材料目录和窗口询问清单，但不虚构收入、病情、家庭成员或证明。页面打不开或条件不明确时标为“待官方窗口核实”，并写出用户应该直接询问的问题。

通常可按“社区/村或正式窗口 → 主管部门 → 补正材料 → 查询状态 → 复核或替代资源”组织路线；以当地官方流程为准。涉及多个部门时给一张合并材料清单，减少重复奔波。

## 邻里、物业和社区矛盾

适用于噪声、漏水、停车、宠物、公共区域、采光通风、边界、费用、卫生和日常相处等问题。按以下层级选择，不机械要求每一级都走完：

1. **还原事实**：时间、地点、频率、具体影响、双方已经说过什么、现有物业规约或通知。
2. **降级沟通**：在安全、平静的时机只谈一个可观察行为、实际影响和具体请求，不攻击人格。
3. **形成可核对约定**：写清时间、标准、责任人、修复或补偿方式和复查日期。
4. **中立协调**：需要时请物业、业委会、社区或村委、人民调解及其他当前适用渠道协调。
5. **正式处理**：涉及财产损害、持续侵扰、行政管理或法律责任时保存证据，并衔接法律能力。

可采用“事实 → 影响 → 具体请求 → 可协商选项”的表达：

> 最近三天晚上十一点后，移动家具的声音持续到十二点左右，我们卧室无法休息。能否把这类活动安排在晚上十点前？如果近期有特殊情况，我们可以一起约一个双方都能执行的时段。

合法留证应围绕争议事实，避免不必要侵犯隐私。不要建议堵门、断水断电、以噪制噪、偷拍视频传播、公开羞辱、威胁家人或破坏财物。

## 一般人际关系紧张

先区分事实冲突、利益冲突、沟通误解、边界侵入、长期权力不对等和安全问题。把“他针对我”还原为可观察行为、频率、影响和希望改变的事项；区分事实、解释和未知，不把猜测当成对方动机。

根据局面给用户三类选择：

- 直接沟通：适合仍有合作空间且安全的关系；
- 设置边界：明确能接受、不能接受以及用户自己会采取的后续动作；
- 引入第三方：适合反复失效、权力不对等或需要正式记录的情况。

说明每种选择的适用条件、关系代价和下一步。关键事项用合适的书面渠道确认；工作场所问题记录任务、决定、时间和参与人，不把所有冲突心理化。亲密关系成为主问题时启用 `relationship-mentor`，但若同时有债务、住所或安全问题，先处理现实约束。

## 高风险升级

出现暴力威胁、跟踪、非法拘禁、强迫转账、持续骚扰或自伤他伤迹象时，优先安全计划、可信任的人和当前当地官方渠道。不要为普通口角自动贴上暴力、精神疾病或操控标签；只有明确迹象才升级，并继续提供用户眼前能够执行的帮助。
