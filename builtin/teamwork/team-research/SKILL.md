# Team Research — 研究团队协作

## 适用场景
当用户要求进行深度研究/分析/报告时，使用 `assemble_team` 组建研究团队。

## 模板选择

### research（默认）
```
模板: research
角色: 研究员 + 分析师 + 撰稿人（并行）
适用: 学术研究、行业报告、技术调研
```

### competitor（竞品分析）
```
模板: competitor
角色: 格局扫描 → [竞对分析×3] → 策略输出（混合）
适用: 竞品分析、市场定位
```

## 执行流程

### 1. 组建团队
```tool
assemble_team template="research" task="{用户的研究课题}"
```

### 2. 处理超时降级
如果 `assemble_team` 超时（常见），手动执行：
1. **研究员** — 用 `web_fetch` 搜索3-5个高质量信息源
2. **分析师** — 分析信息，识别模式、矛盾点、关键发现
3. **撰稿人** — 整合成结构化报告

### 3. 输出报告格式
```markdown
# {课题} 研究报告

## 执行摘要
...

## 研究方法
...

## 关键发现
...

## 分析与洞察
...

## 结论与建议
...

## 参考资料
...
```

### 4. 保存报告
```tool
write_file path="storage/research_{课题}_YYYY-MM-DD.md" content="{报告内容}"
```

## 最佳实践
1. **研究课题要具体** — 避免过于宽泛的课题（如"AI"），改为"AI大模型在医疗诊断中的应用"
2. **多源交叉验证** — 研究员至少使用3个独立信息源
3. **区分事实与观点** — 报告中明确标注
4. **信息盲区标注** — 分析师标注"无法确认"的信息
5. **报告有行动建议** — 撰稿人确保报告结尾有可执行的建议
