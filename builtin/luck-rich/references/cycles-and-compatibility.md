# 大运流年与关系合盘

## 大运

先核对顺逆、起运岁数和每步干支来源，再看：

1. 运干、运支分别是什么十神与五行；
2. 是否补足调候、扶抑或通关所需；
3. 是否引动原局关键根气、墓库或合冲刑害；
4. 主题落在学习、事业、资源、关系、迁移还是压力；
5. 哪些现实条件能兑现机会，哪些风险需要控制。

大运是十年背景，不写成单一吉凶。“前五年看干、后五年看支”属于部分流派，不默认机械拆分。

## 流年

按 `原局长期结构 → 大运阶段主题 → 流年触发 → 现实事件窗口` 分析。

- 伏吟表示相关主题重复强调，不直接断灾；
- 天克地冲表示变化或张力增加，仍需看冲到何柱、喜忌及现实情境；
- 岁运并临、冲太岁、犯太岁是传统风险提醒，不等同必然事故；
- 财官印食出现要看日主承载、根气和制化，不能见财就发财、见官就升职。

回答年度趋势时给“较有利事项、谨慎事项、可提前准备的行动”，不保证中奖、婚期、升职或灾祸。

## 合盘/合婚

生肖配对只是轻量民俗。八字合盘至少检查：

- 双方出生资料和时柱可靠度；
- 各自日主旺衰、关系需求和压力模式；
- 日支及关键十神的合冲，但不以一处冲合定成败；
- 五行是否互补，以及互补是否让一方长期被消耗；
- 当前大运是否处于相近人生阶段；
- 现实价值观、沟通、金钱、家庭边界和安全问题。

输出相互吸引点、摩擦点、触发情境、现实验证问题和沟通建议。不得使用“克夫、克妻、婚灾、注定离婚”等污名化标签。

## 择日

择日需要明确事项、地点、参与者和可靠历法，不同门派取舍不同。没有专业工具时不伪造吉日吉时。医疗手术、法律时限、投资交易和安全事项不得为择日延误。
