# 准确度与校准协议

本文件用于所有完整命盘解读，以及“不准、重算、两个排盘冲突、结合经历校时/校准”的请求。目标是提高可复现性、区分度和诚实度，不承诺超自然预测准确率。

## 一、冻结输入与口径

先建立一份本次会话内不变的记录：

```text
体系：八字 / 西方占星 / 生肖 / 综合
历法：公历 / 农历；农历是否闰月
出生：年月日、当地时间、时间精确度（记录/回忆/约数/未知）
地点：城市、国家、当时法定时区及夏令时
计算口径：立春/春节、子时换日、是否真太阳时、黄道与宫制、起运算法
盘面来源：工具名/版本或用户提供的完整盘面
问题：主题与明确时间范围
```

没有可靠工具时不把出生日期自行转换为日柱、起运岁数、行星度数、宫位或相位。用户提供两个盘时，先制作差异表，只比较输入、交节、时区、夏令时、换日、真太阳时、宫制和起运算法；不得选择“更像本人”的结果当正确盘。

## 二、事实层与解释层分开

先列盘面事实，再解释。每个核心主张使用同一结构：

| 字段 | 要求 |
|---|---|
| 盘面事实 | 可由盘面直接核对的干支、十神、月令、根气、相位或宫位 |
| 规则 | 本次采用的传统规则或流派口径 |
| 候选表现 | 足够具体但不是必然事件的现实范围 |
| 反向条件 | 哪种配置、经历或口径会削弱/推翻结论 |
| 把握 | 较高 / 中等 / 较低，并说明原因 |

不能填出“盘面事实”的性格句删除。不要用一体两面把所有结果都包住；如果两个方向都可能，明确写竞争解释及各自判别条件。

## 三、减少泛化命中

- 避免“重感情但不善表达、看似随和其实有原则、年轻时辛苦以后会好”等普适句。
- 不一次罗列十多个性格和事件供用户自行对号入座；完整解读只保留三到五个区分度最高的主题。
- 不用用户问题本身反推命盘，例如用户问财运就断“近期一定有财务机会”。
- 不从职业、婚姻状态或疾病反推唯一时辰；校时最多保留多个候选并说明各自可检验差异。
- 用户否认后不立刻改成相反结论；先检查输入、口径、原判断是否过宽，再降级或撤回。

## 四、历史回测

回测前先冻结二至四个候选主题及其时间窗口，然后请用户提供带年份或年龄段的事实。问题保持中性，例如：

- 哪几个年份发生过可核实的迁居、转学、换行业或职责显著变化？
- 哪段时间收入结构、负债或家庭资源责任发生过明显改变？
- 哪段关系或合作在什么时间开始、转折或结束？
- 哪些本应明显的窗口实际没有发生对应变化？

结果分为 `支持`、`矛盾`、`资料不足`。必须保留矛盾项；强矛盾优先触发出生时间/排盘口径复核或降低把握，而不是增加神煞、空亡等辅助术语补救。

## 五、可信度规则

- **较高**：盘面已审计，同一主线有多个独立配置支持，反证弱，并与至少两个不同领域或阶段的用户事实一致。
- **中等**：盘面可靠但存在流派差异，或主线有支持也有反证，回测样本有限。
- **较低**：时辰/口径不明、只有单一配置、边界日期、尚无回测或解释可替代性强。

可信度描述的是“这套传统解释在当前输入和口径下是否自洽”，不等于科学预测概率。不得编造百分比。

## 六、重算触发条件

出现以下任一项，停止沿用旧结论：公农历混淆、闰月遗漏、出生地/时区错误、夏令时遗漏、节气或子时边界跨越、真太阳时导致跨时辰、两个可靠工具日柱不一致、起运方向/岁数来源不明。先修正盘面，再从旺衰、十神、格局和岁运重新推导，不能只局部改一句结论。
