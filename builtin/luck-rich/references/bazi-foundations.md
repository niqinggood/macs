# 八字基础规则

## 十天干

| 天干 | 阴阳 | 五行 | 常见意象 |
|---|---|---|---|
| 甲 | 阳 | 木 | 生发、直立、开拓 |
| 乙 | 阴 | 木 | 柔韧、协调、延展 |
| 丙 | 阳 | 火 | 明朗、外显、传播 |
| 丁 | 阴 | 火 | 专注、细致、持续 |
| 戊 | 阳 | 土 | 承载、稳定、边界 |
| 己 | 阴 | 土 | 培育、整合、务实 |
| 庚 | 阳 | 金 | 决断、执行、改革 |
| 辛 | 阴 | 金 | 精细、审美、规则 |
| 壬 | 阳 | 水 | 流动、连接、视野 |
| 癸 | 阴 | 水 | 渗透、感受、研究 |

意象只是传统类比，必须结合强弱、位置和组合，不能据一个天干定性格。

## 五行生克

- 相生：木生火、火生土、土生金、金生水、水生木。
- 相克：木克土、土克水、水克火、火克金、金克木。
- 生克不是简单吉凶：生扶过多可能壅滞，克制适度可能形成秩序；关键是日主承受力与全局制化。

## 十神算法

十神永远以 **日干（日主）** 为参照：

| 与日主关系 | 同阴阳 | 异阴阳 |
|---|---|---|
| 同五行 | 比肩 | 劫财 |
| 日主所生 | 食神 | 伤官 |
| 日主所克 | 偏财 | 正财 |
| 克日主 | 七杀/偏官 | 正官 |
| 生日主 | 偏印/枭神 | 正印 |

“正/偏”是阴阳关系，不代表道德好坏。解释十神时同时看得令、透干、根气、制化和柱位。

- 比劫：自我、同辈、竞争、协作和资源分配；
- 食伤：表达、创造、技能、产出、反规则和照料；
- 财星：资源、交易、执行成果、现实关系和责任；
- 官杀：规则、职位、压力、约束、风险和组织；
- 印星：学习、资质、保护、思想、支持系统和恢复。

不能用“男命财为妻、女命官为夫”单点决定婚姻；现代关系解读至少同时看日支、十神配置、沟通模式和现实经历。

## 地支主要关系

- 六合：子丑、寅亥、卯戌、辰酉、巳申、午未。
- 六冲：子午、丑未、寅申、卯酉、辰戌、巳亥。
- 三合：申子辰水、亥卯未木、寅午戌火、巳酉丑金。
- 三会：亥子丑水、寅卯辰木、巳午未火、申酉戌金。
- 六害：子未、丑午、寅巳、卯辰、申亥、酉戌。
- 常见三刑：寅巳申、丑未戌、子卯；辰午酉亥常按自刑讨论。

“破”、暗合及部分刑法在流派间差异较大，不放在核心判断前。任何合局或会局都要看月令、透干、根气、位置和破坏条件；见合不必化，见冲不必凶。

## 四柱位置

- 年柱：早期环境、家族和外部圈层；
- 月柱：季节月令、成长/工作环境和结构核心；
- 日干：分析中心；日支常称配偶宫，也表示贴身环境；
- 时柱：后期发展、长期产出、计划和子女议题的传统观察位。

位置含义只是解释维度，不是事件保证。优先解释参与旺衰、十神和组合的事实，再谈宫位象征。
