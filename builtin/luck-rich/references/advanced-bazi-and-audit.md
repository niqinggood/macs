# 八字进阶规则与审计

用于复杂盘面和结论复核。主线始终是月令、通根、透干、旺衰、十神与制化；辅助体系不能绕过主线直接断事。

## 天干关系

- 五合为甲己、乙庚、丙辛、丁壬、戊癸。见合先判断相邻、得令、引化和阻隔；“有合”不等于“必化”。
- 生克要同时看强弱与位置。透出使藏干主题更显性，但无根、失令或受制的透干不能按强势主题处理。
- 争合、妒合、遥合只是候选解释，必须说明参与干、位置和是否真的改变结构。

## 地支复杂关系

- 六合、三合、三会、六冲和六害见基础文件。破常用子酉、丑辰、寅亥、卯午、巳申、未戌；不同流派权重差异大，不能与冲同权。
- 刑要区分寅巳申、丑未戌、子卯及辰午酉亥自刑等常见口径；是否成立要看组合完整度、重复、岁运触发和现实主题。
- 合、冲、刑、害并见时不按数量投票。先看月令和关键用神是否被改变，再看哪一组贴近日支、月令或岁运触发点。
- 冲可表示移动、分离、替换或矛盾，不自动等于灾祸；合可表示牵制或绑定，不自动等于吉利。

## 十二长生、空亡、纳音与神煞

- 十二长生可描述五行阶段，阴干顺逆和用途有流派差异。只作旺衰旁证，不能覆盖月令、根气和制化。
- 空亡须基于可靠日柱和旬空表。它不等于“没有”，可讨论延迟、名实落差或作用减弱，但须声明所用口径。
- 纳音只作传统象征，不能用“某命”代替日主旺衰和十神分析。
- 桃花、驿马、华盖、文昌、羊刃、天乙贵人等神煞，只在主结构支持相同主题时作补充；不得仅凭一个神煞断婚变、事故、学历、疾病或贵人。

## 特殊格局审查

讨论从格、专旺或化气前逐项记录：

1. 月令是否形成明确主导气势；
2. 日主是否仍有根、印比或反向力量；
3. 透干是否顺从同一气势，是否存在有效制化；
4. 合化条件是否完整，而非只有一组天干相合；
5. 过去大运在顺势与逆势阶段是否出现一致、可核实的差异。

有明显反证时退回普通旺衰与十神结构，不为了显得高级强定特殊格局。

## 喜忌审计表

每个“喜某五行/忌某五行”的结论至少回答：

- 它解决的是寒暖燥湿、强弱失衡、两强相战还是病药问题；
- 通过哪个干支进入，是否同时引发新的合冲刑害；
- 原局需要的是五行本身，还是某一具体十神功能；
- 在什么大运和现实条件下可能成为助力；
- 哪条反证会推翻当前判断。

不能把颜色、饰品、方位或改名当成主要“补五行”手段。现实建议优先落到技能、工作环境、资源配置、沟通和风险管理。

## 结论一致性检查

- 四柱、性别口径、时区、真太阳时和起运表是否来自同一排盘体系；
- 十神阴阳正偏是否逐项算对；
- 旺衰是否解释了月令、根气、透干和制化，而不是只数五行；
- 格局、用神、十神主题与岁运是否一致；
- 同一冲合是否在不同段落被写成相反含义；
- 是否把辅助体系写成决定性结论；
- 是否给出现实验证问题，而不是只用宽泛形容词制造命中感。
