# 生肖与西方星座

## 生肖

十二生肖依次为鼠、牛、虎、兔、龙、蛇、马、羊、猴、鸡、狗、猪，对应子丑寅卯辰巳午未申酉戌亥。

民俗原型可轻量描述：鼠机敏与资源意识；牛稳定与耐力；虎行动与独立；兔协调与谨慎；龙理想与号召；蛇观察与策略；马自由与速度；羊感受与合作；猴学习与变化；鸡秩序与表达；狗忠诚与原则；猪包容与享受。每种都写优势和过度使用的代价。

六合、三合、相冲可作互动话题，不能据此判断婚姻或合作成败。春节和立春界年可能产生不同生肖口径，临界出生者先说明采用哪一种。

## 太阳星座

以下热带黄道日期是近似范围，临界日需用年份、时间、地点和星历核对：

| 星座 | 常见日期 | 元素 | 模式 |
|---|---|---|---|
| 白羊 | 3/21—4/19 | 火 | 开创 |
| 金牛 | 4/20—5/20 | 土 | 固定 |
| 双子 | 5/21—6/21 | 风 | 变动 |
| 巨蟹 | 6/22—7/22 | 水 | 开创 |
| 狮子 | 7/23—8/22 | 火 | 固定 |
| 处女 | 8/23—9/22 | 土 | 变动 |
| 天秤 | 9/23—10/23 | 风 | 开创 |
| 天蝎 | 10/24—11/22 | 水 | 固定 |
| 射手 | 11/23—12/21 | 火 | 变动 |
| 摩羯 | 12/22—1/19 | 土 | 开创 |
| 水瓶 | 1/20—2/18 | 风 | 固定 |
| 双鱼 | 2/19—3/20 | 水 | 变动 |

元素描述倾向：火重行动与表达，土重稳定与现实，风重思考与连接，水重感受与联结。模式描述行动方式：开创启动、固定维持、变动调整。

只知道太阳星座时不能假装拥有完整星盘。完整盘至少需要准确出生时间、地点、时区和可靠星历，并综合太阳、月亮、上升、行星、宫位与相位。时间未知时上升和宫位不可用，月亮也可能在临界日换座。

基础语法：行星表示“什么功能”，星座表示“以什么方式”，宫位表示“在哪个领域”，相位表示功能如何协作或拉扯。不能仅凭金星断婚恋、二宫断财富或六宫断疾病。
