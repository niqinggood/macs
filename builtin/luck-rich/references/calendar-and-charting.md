# 历法与排盘约定

## 先声明口径

八字流派在换日、真太阳时和起运算法上存在差异。输出盘面前说明口径；用户已有排盘时优先沿用，不静默改盘。

- 八字年柱通常以 **立春** 为界，不以公历元旦或农历正月初一为界。
- 生肖民俗通常以 **农历春节** 换年；八字生肖可随年柱按立春换年。春节至立春附近出生者必须说明两种口径可能不同。
- 月柱按节气月划分：寅月从立春起、卯月从惊蛰起，依次到丑月从小寒起；不是农历初一换月。
- 日柱需要可靠万年历、儒略日算法或专业排盘工具。没有经过测试的计算能力时不凭记忆手算。
- 时柱地支按两个小时一段，但子时存在 23 点或 0 点换日等流派差异；23:00—00:59 出生必须标注口径。
- 真太阳时校正需要出生地经度、法定时区和当年夏令时。时辰边界附近应展示校正前后是否跨时辰。

## 月干五虎遁

月支固定从寅月开始，寅月月干按年干分组：

| 年干 | 寅月起干 |
|---|---|
| 甲、己 | 丙寅 |
| 乙、庚 | 戊寅 |
| 丙、辛 | 庚寅 |
| 丁、壬 | 壬寅 |
| 戊、癸 | 甲寅 |

随后按天干顺序逐月推进。节气交接当天必须使用精确交节时间，不能只看日期。

## 时干五鼠遁

先由可靠工具确定日干与时支，再按日干确定子时起干：

| 日干 | 子时起干 |
|---|---|
| 甲、己 | 甲子 |
| 乙、庚 | 丙子 |
| 丙、辛 | 戊子 |
| 丁、壬 | 庚子 |
| 戊、癸 | 壬子 |

其余时辰按天干顺序推进。常见民用时支范围：子 23—1、丑 1—3、寅 3—5、卯 5—7、辰 7—9、巳 9—11、午 11—13、未 13—15、申 15—17、酉 17—19、戌 19—21、亥 21—23。

## 大运

常见规则以年干阴阳与出生性别决定顺逆：阳年男、阴年女顺排；阴年男、阳年女逆排。阳干为甲丙戊庚壬，阴干为乙丁己辛癸。不同流派或用户身份偏好可能采用其他规则，必须说明。

起运岁数常按出生时刻到顺排下一个节、或逆排上一个节的时间差换算，常见口径为三天折一年、一天折四个月；精确算法和取“节”还是“气”存在流派差异。没有可靠工具时只解释用户提供的大运，不自行生成起运岁数。

## 输入核验

- 日期是公历还是农历，农历是否闰月；
- 出生时间是医院记录、家人回忆还是约数；
- 出生城市、国家、法定时区和夏令时；
- 是否要求真太阳时、采用哪种子时换日；
- 排盘工具名称或完整四柱/大运文本；
- 不同工具结果不一致时，先比较交节、时区、真太阳时和子时口径。

不能可靠排盘时直接请用户提供四柱：

> 日柱/时柱需要可靠历法计算。为避免十神和大运全部错位，请提供排盘工具生成的年柱、月柱、日柱、时柱和大运列表；时辰未知时，我可以先分析三柱，并标出不能判断的部分。
