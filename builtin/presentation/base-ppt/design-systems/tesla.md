# Tesla Design System

## Philosophy
Futuristic, bold, cinematic. Full-bleed dark imagery, minimal text overlay, high drama. Product-as-hero. Feels like a sci-fi movie title sequence. Large typography, extreme contrast, red accent as the only color pop.

## Color Palette
| Role | Hex | Usage |
|------|-----|-------|
| Background | #000000 | All slides (always dark) |
| Surface | #111111 | Cards, panels |
| Text Primary | #ffffff | All text |
| Text Secondary | #999999 | Captions, disclaimers |
| Tesla Red | #e82127 | Sole accent — CTAs, highlights, underlines |
| Dark Gray | #1a1a1a | Subtle surfaces |

## Typography
- **Hero Title**: System-ui, sans-serif — 64-96px, 700 weight, -1.5px tracking, white
- **Heading**: System-ui — 36-48px, 500 weight
- **Body**: System-ui — 18-20px, 300 weight (light), line-height 1.6
- **Stats/Numbers**: System-ui — 48-64px, 300 weight (thin, elegant)

## Layout
- **Hero**: Full-bleed product image as background, minimal text overlay — product name + one key stat + CTA
- **Stats slides**: Single enormous number centered (72-96px, thin weight), small label below
- **Feature slides**: Split screen — product image left (60%) + 2-3 feature bullets right (40%)
- **Comparison**: Split screen left/right, dark bg, thin divider line
- **Spacing**: Extreme — very little text per slide, huge numbers, massive whitespace

## Components
- **Stat cards**: Giant number (64-96px, 300 weight, white) + tiny label (14px, #999), 2-3 per slide with generous spacing
- **Feature lists**: 3-4 items max per slide, each with small red accent dot + 24px white text, wide spacing
- **CTA buttons**: White outlined (1px border), 16px padding, hover fills white
- **Progress/range**: Thin 2px line, red dot indicator, white labels at min/max
- **Spec tables**: Minimal — white text on black, thin #333 dividers, monospace numbers

## Imagery
- Always full-bleed, edge-to-edge
- Product shots: dramatic lighting, dark background
- No borders, no frames, no shadows
- Video/motion preferred over static when possible

## Tone
- Confident, aspirational, visionary
- Minimal copy — let the product and numbers speak
- Present tense, declarative statements
- Never use marketing fluff — facts and specs only
