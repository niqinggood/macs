# Airbnb Design System

## Philosophy
Warm, human, travel-inspired. Photography-forward. Rounded everything. Generous whitespace. Feels like a premium travel magazine. Soft shadows, warm color temperature, approachable typography.

## Color Palette
| Role | Hex | Usage |
|------|-----|-------|
| Background | #ffffff | Default |
| Warm BG | #f7f5f2 | Warm sections, testimonials |
| Text Primary | #222222 | Headings, body |
| Text Secondary | #717171 | Captions |
| Primary Red | #ff385c | Brand accent, CTAs |
| Primary Dark | #d70466 | Hover, emphasis |
| Warm Orange | #e0795c | Secondary accent |
| Ocean Blue | #008489 | Tertiary accent |
| Success Green | #008a05 | Positive metrics |
| Border | #ebebeb | Card borders |

## Typography
- **Display**: 'Circular', 'Plus Jakarta Sans', system-ui — 48-64px, 600-700 weight
- **Heading**: 'Circular', 'Plus Jakarta Sans' — 28-36px, 500-600 weight
- **Body**: 'Circular', 'Plus Jakarta Sans' — 16-18px, 400 weight, line-height 1.5
- **Caption**: 14px, color #717171

## Layout
- **Hero**: Full-bleed photo background with overlay gradient (black 40% → transparent), large white heading + CTA
- **Gallery**: 2×2 or 3×2 image grid with uniform 16px gap, rounded corners
- **Content**: Centered single-column for narrative, 2-column for comparison
- **Spacing**: Very generous — 120px section padding, 48px between elements
- **Margins**: 80-120px on desktop slides

## Components
- **Cards**: White or warm bg, 12-16px border-radius, soft shadow (0 4px 16px rgba(0,0,0,0.06)), 24-32px padding
- **Image cards**: Photo fills top 60%, text content below, rounded 16px, shadow
- **Testimonials**: Large quote marks in primary red (96px, low opacity), quote text 20-24px, avatar + name + role below
- **Stat cards**: Large number in primary red + label below, 2-4 per row
- **Tables**: Simple, #ebebeb borders, no alternating rows, rounded 8px
- **Rating stars**: Primary red filled stars

## Photography Style
- Warm, natural light
- People in real contexts (not stock photo poses)
- Local details and textures
- 16:9 or 4:3 aspect ratio
- Full-bleed whenever possible
