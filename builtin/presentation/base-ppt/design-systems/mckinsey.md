# McKinsey / Professional Consulting Design System

## Philosophy
Authoritative, structured, data-driven. Every slide tells a clear story with an action title. Pyramid principle: conclusion first, then supporting evidence. Clean, no decoration, maximum information density without clutter.

## Color Palette
| Role | Hex | Usage |
|------|-----|-------|
| Background | #ffffff | All slides |
| Text Primary | #1a1a2e | Headings, body |
| Text Secondary | #6b7280 | Footnotes, sources |
| Primary Blue | #003d99 | Action titles, headers, emphasis |
| Secondary Blue | #4a90d9 | Charts, icons, secondary elements |
| Accent Orange | #f5a623 | Key callouts, important numbers |
| Border | #d1d5db | Table borders, dividers |
| Light BG | #f0f4f8 | Table headers, sidebar bg |

## Typography
- **Action Title**: Arial, Calibri — 24-28pt, bold, primary blue, must be a complete sentence with insight
- **Subtitle**: Arial — 18-20pt, regular, dark gray
- **Body**: Arial, Calibri — 12-14pt, regular, 1.4 line-height
- **Footnote/Source**: Arial — 8-9pt, secondary text, bottom-left

## Layout
- **Action title**: Top of every slide, 2-line max, primary blue, bold
- **Content area**: Below title, organized in 2-3 columns or rows
- **Footnote**: Bottom 5% of slide, source citations
- **Logo**: Top-right corner, small
- **Margins**: 0.8 inch all sides
- **Spacing**: Tight but readable — 12-16px between related elements

## Components
- **Executive summary box**: Light blue bg (#e8f0fe), 2px left border primary blue, 16px padding, contains "Bottom line:" lead-in
- **KPI bar**: Horizontal row of 3-5 metrics, each with large number + small label + delta indicator (▲ green / ▼ red)
- **Waterfall chart**: For showing drivers of change (variance analysis)
- **Tables**: Compact, header row with primary blue bg + white text, body rows alternating white/#fafbfc, cell padding 6-8px, font size 10-11pt
- **Callout boxes**: Orange left border for key insights, gray left border for supporting details
- **Bullets**: Short phrases, not sentences. Max 5 per slide. 2-level max depth

## Slide Types
1. **Executive Summary**: Action title + 3-5 key findings in callout boxes + bottom line
2. **Analysis Deep-dive**: Title + chart/table (70% area) + 2-3 insight bullets (30% area)
3. **Data Table**: Title + full-width table with highlighted rows
4. **Framework/Methodology**: Title + process flow diagram + brief explanation
5. **Recommendation**: Title + 3-column layout with recommendation / rationale / impact

## Golden Rules
- Every slide must pass the "elevator test": reader gets the main point in 5 seconds
- One message per slide — if there are two points, use two slides
- All data must have source citations (footnote, 8pt, gray)
- Numbers > words; charts > tables; tables > bullet points
