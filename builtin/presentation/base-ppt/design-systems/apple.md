# Apple Design System

## Philosophy
Minimalist, product-focused. Less is more. Every element must earn its place. Heavy use of whitespace, large product imagery, concise copy. The design disappears to let the content speak.

## Color Palette
| Role | Hex | Usage |
|------|-----|-------|
| Background | #ffffff | Slide background |
| Dark BG | #000000 | Hero slides, footer |
| Text Primary | #1d1d1f | Body, headings |
| Text Secondary | #86868b | Subtitles, captions |
| Accent | #0071e3 | CTAs, links, highlights |
| Gradient Start | #0077ed | Hero gradient |
| Gradient End | #6e5eff | Hero gradient |

## Typography
- **Display/Title**: SF Pro Display, system-ui, -apple-system — 48-64px, tracking -0.5px
- **Heading**: SF Pro Display — 32-40px, semibold (600)
- **Body**: SF Pro Text — 17-19px, regular (400), line-height 1.5
- **Caption**: SF Pro Text — 14px, color #86868b

## Layout
- **Hero slides**: Full-bleed dark background, centered product name + one-liner, large product image below
- **Content slides**: 60/40 split (text left, image right) or centered single-column
- **Section dividers**: Full dark bg, single word or phrase centered, large
- **Spacing**: Generous — 80-120px between sections, 40px between elements
- **Grid**: 12-column, 80px gutter

## Components
- **Cards**: White, subtle shadow (0 2px 8px rgba(0,0,0,0.08)), 16px border-radius, centered content
- **Images**: Full-width or centered, no border, optional subtle shadow
- **Tables**: Minimal — thin #e5e5e5 borders, no header background, clean text alignment
- **CTAs**: Pill buttons, accent blue, 12px horizontal padding
- **Icons**: SF Symbols style, line-based, 24-32px

## Motion
- Subtle fade-in, no bounce or overshoot
- 0.3s ease-out for all transitions
- Stagger child elements by 0.05s
