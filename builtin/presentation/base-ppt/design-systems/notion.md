# Notion Design System

## Philosophy
Clean, functional, documentation-style. Minimalist but warm. Emoji-friendly, serif-less, paper-like. Information hierarchy through font weight and size, not color. Feels like a well-organized document, not a "presentation."

## Color Palette
| Role | Hex | Usage |
|------|-----|-------|
| Background | #ffffff | Default |
| Surface | #f7f6f3 | Cards, callouts |
| Text Primary | #37352f | All body text |
| Text Secondary | #9b9a97 | Captions, metadata |
| Accent | #2383e2 | Links, buttons |
| Red | #e03e3e | Important callouts |
| Brown BG | #f1ece1 | Warm callout |
| Gray BG | #f1f1ef | Neutral callout |
| Blue BG | #e8f0fe | Info callout |
| Border | #e9e9e7 | Dividers, table borders |

## Typography
- **Display**: Inter, system-ui, 'Noto Sans SC' — 40-48px, 700
- **Heading 1**: Inter — 30-36px, 600
- **Heading 2**: Inter — 22-26px, 600
- **Heading 3**: Inter — 18-20px, 600
- **Body**: Inter, system-ui — 16px, 400, line-height 1.5
- **Caption**: Inter — 14px, color #9b9a97

## Layout
- **Single column**: Centered, max-width 720px, like a document
- **Two column**: For comparison or image+text layouts
- **Gallery**: For team bios, product features, portfolio
- **Margins**: 100px left/right on standard slides
- **Spacing**: 24px between paragraphs, 40px between sections

## Components
- **Callout blocks**: Rounded (4px), left icon (emoji or SVG), background color from semantic palette, 16px padding
- **Tables**: Simple, alternating row colors (white/gray), thin borders
- **Cards**: White bg, 1px #e9e9e7 border, 4px radius, hover lifts shadow slightly
- **Toggle/Accordion**: Triangle icon, bold label, collapsible content
- **Dividers**: 1px #e9e9e7 line, 24px vertical margin
- **Embeds**: Images full-width, 4px radius, optional caption below in secondary text

## Iconography
- Emoji-first for simple concepts
- SVG icons for UI/product references
- Consistent 24px size for inline icons
- Icons always paired with text labels

## Tone
- Warm, human, approachable
- Use sentence case (not Title Case) for headings
- Contractions OK, conversational tone
- "We" and "you" pronouns encouraged
