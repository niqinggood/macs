## Technical Architecture

@viewpoint Multi-agent systems require three integrated layers: Planning for task decomposition, Memory for context persistence, and Orchestration for parallel execution.

### Planning & Execution
- Task decomposition with dependency graphs
- Deterministic vs exploratory classification
- Real-time checkpoint recovery
- Parallel sub-agent orchestration

### Memory & Context  
- Hierarchical: working / episodic / semantic
- Auto-compression at token thresholds
- Cross-session knowledge persistence
- Vector-based semantic retrieval
