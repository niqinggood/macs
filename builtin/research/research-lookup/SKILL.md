# 研究信息检索

## 概述

提供实时研究信息检索能力。根据查询内容智能选择最佳搜索策略——通用搜索优先，学术搜索按需使用，深度研究显式触发。

## 适用场景

- **最新研究信息**：专题研究、论文、发现
- **事实核查**：交叉验证数据、统计或声明
- **背景研究**：为写作和分析收集支持证据
- **引用来源**：找到可引用的相关研究和数据
- **市场/行业数据**：当前统计、趋势、竞争情报
- **最新动态**：新兴趋势、突破、公告

---

## 搜索策略路由

```
查询到达
    |
    +-- 含学术关键词？（论文、DOI、期刊、系统性综述、Meta分析等）
    |       是 → 优先学术来源（Google Scholar、PubMed、arXiv 等）
    |
    +-- 需要深度多源综合？（用户明确要求"深度研究"、"全面分析"）
    |       是 → 多轮搜索 + 综合
    |
    +-- 其他所有（通用研究、市场数据、技术信息、分析）
            → 通用搜索（快速、默认）
```

## 核心能力

### 1. 通用研究查询（默认）

适用查询示例：
- "2025年基因编辑最新进展"
- "AI在医疗行业的采用率统计"
- "全球可再生能源市场趋势和预测"
- "某行业市场规模和增长率"

**输出包括：**
- 综合发现，附内联引用
- 优先学术来源
- 具体事实、数字和日期
- 来源分类列表

### 2. 学术搜索

适用查询示例：
- "查找关于 Transformer 注意力机制的论文"
- "免疫治疗在非小细胞肺癌中的系统综述"
- "引用 AlphaFold 原始论文及其最有影响力的后续研究"
- "CRISPR 脱靶效应的临床研究"

**输出包括：**
- 学术文献关键发现摘要
- 5-8 个高质量引用（作者、标题、期刊、年份、DOI）
- 引用数量和来源等级
- 关键统计和方法亮点
- 研究缺口和未来方向

### 3. 深度研究（按需触发）

仅当用户明确要求深度或全面研究时使用。提供全面的多源综合。

### 4. 技术与方法论信息

快速查询技术规范、协议或方法论。

### 5. 统计与市场数据

查询当前市场数据和统计信息。

## 论文质量优先级

### 引用量排名

| 论文年龄 | 引用量门槛 | 分类 |
|---------|-----------|------|
| 0-3年 | 20+ | 值得关注 |
| 0-3年 | 100+ | 高度影响力 |
| 3-7年 | 100+ | 显著 |
| 3-7年 | 500+ | 里程碑论文 |
| 7年+ | 500+ | 开创性工作 |
| 7年+ | 1000+ | 奠基性 |

### 来源质量分级

**Tier 1 - 顶级来源**（始终优先）：
- 综合科学：Nature, Science, Cell, PNAS
- 医学：NEJM, Lancet, JAMA, BMJ
- AI/CS：NeurIPS, ICML, ICLR, ACL, CVPR

**Tier 2 - 高影响力专业**（强烈偏好）：
- 影响因子 > 10 的期刊
- 子领域顶会

**Tier 3 - 受尊敬专业**（相关时包含）：
- 影响因子 5-10 的期刊

## 结果保存与记录

每次研究查询的结果建议保存到项目工作目录：

```
项目目录/
├── sources/                    # 研究结果保存
│   ├── research_<主题>.md     # 通用研究结果
│   ├── papers_<主题>.md       # 学术论文搜索结果
│   └── deep_<主题>.md         # 深度研究结果
```

**保存原则：**
1. **可复现性** — 每个引用和声明可追溯到原始研究来源
2. **上下文恢复** — 如果上下文被压缩，保存的结果可重新读取无需重新查询
3. **审计轨迹** — sources/ 文件夹记录研究信息收集过程
4. **跨章节复用** — 多个章节可引用同一保存的研究
5. **成本效率** — 在新查询前先检查 sources/ 是否有已有结果

### 查询前先检查已有结果

进行新查询前，先检查是否已有相关结果，避免重复查询。

## 与写作的集成

此 skill 通过以下方式增强写作质量：

1. **文献综述支持** — 收集当前研究用于引言和讨论
2. **方法验证** — 对照当前标准验证方法论
3. **结果情境化** — 与最新类似研究进行比较
4. **论证增强** — 用最新证据支持论点
5. **引用管理** — 提供标准格式的引用

- **market-research-reports**：为报告各章节提供数据和研究支撑
- **hypothesis-generation**：在文献搜索阶段提供信息来源
- **critical-thinking**：提供需要批判性评估的研究材料
- **lead-researcher**：补充行业和公司研究数据

## 注意事项

- 始终标注信息来源和获取日期
- 优先使用公开可访问的来源
- 交叉验证关键数据点（多来源对照）
- 承认信息局限性（时效性、可及性、偏差等）
