# 中西医双视角解读指南

在同一份事实快照上形成两个彼此独立、可以互补但不能互相证明的解释视角。西医临床视角负责急症识别、检查效度、鉴别方向和就医路径；中医视角用于整理症状整体、证候倾向和可与合格中医师讨论的调护方向。

## 基本立场

- 先安全，后解释。红旗症状、临床复测和必要转诊不因任何中医解释而降级。
- 先事实，后推断。分别标记病历/测量事实、西医临床推断、中医辨证线索和未知信息。
- 不强求一致。两个视角若暂时不同，说明各自依据和能区分方向的信息，不生造“中西医一一对应”。
- 不为完整而猜测。中医辨证依赖望、闻、问、切和病程；只有化验、影像或设备评分时，也要给出低置信度的 `资料型待辨方向` 和鉴别问题，但不能写成已经确立的主证。
- 中医是补充性视角，不代替或推迟常规诊疗。采用中药、针灸等干预前，应考虑资质、证据、药物相互作用和个体风险。

## 双视角生成流程

1. **建立共同事实层**：记录症状时间线、既往病史、用药和过敏、直接检查、参考范围、设备/模型估算、数据质量和红旗症状。
2. **完成西医临床层**：回答主要发现是什么，常见机制和鉴别方向是什么，哪些信息支持或反驳，怎样复测、就诊或处置。
3. **评定辨证证据层级**：按 A/B/C 三级处理，不把设备数据伪装成四诊资料。
4. **形成中医线索层**：A/B 级只写一个主要 `证候倾向` 和至多一个备选方向；C 级覆盖所有有资料的数据域（通常 3–6 组），每组展开少量相关子方向但不排序。同时给出推理路径、支持线索、矛盾/缺失线索和面诊确认点。
5. **合并行动层**：急诊、临床确认和科室路径在前；共同适用的低风险生活措施在后；中药、针灸和治法只作为与合格专业人员讨论的选项。

## 辨证证据层级与必须输出的内容

| 层级 | 已有资料 | 可以怎么写 | 不可以怎么写 |
|---|---|---|---|
| A | 症状组合、病程，加可信舌象/临床脉象 | `初步证候倾向：……；兼夹/备选：……`，列支持与反证 | 写成确诊、承诺疗效 |
| B | 有症状组合和病程，缺舌脉 | `较可能的证候方向：……`，明确需舌脉确认 | 补写不存在的舌苔、脉象 |
| C | 只有化验、影像、体型或设备/模型数据 | `资料型待辨方向`，按数据域列候选轴和鉴别问题 | 指定主证、把单个指标直接等同证型 |

中国患者标准版/完整版和安安 `med_guid` 会话不得因为只有 C 级资料就省略中医内容。C 级至少包含：`辨证层级`、现有资料覆盖的全部 `待辨方向组`、组内细分方向、辨证路径、关键鉴别问题，以及饮食/起居/运动/情志中的低风险调护原则。完全没有可用健康事实时才只写 `中医辨证信息不足`。

## 中医诊断思路

中医部分不能只是列证型名。按照下面的次序展示推理，资料缺失时明确写 `暂不能判断`：

1. **病程与主诉**：区分长期体质、近期证候和急性变化，记录诱因、昼夜、进食、劳累及情绪关系。
2. **八纲定性**：先辨表里，再看寒热、虚实，最后用阴阳作总括。设备/模型资料通常不足以完成这一步，重点转化为寒热、汗、口渴、二便等追问。
3. **病位定位**：根据实际症状讨论心、肝、脾、肺、肾及经络关联，不由单个现代指标直接定位脏腑。
4. **气血津液**：从气虚/气滞、血虚/血瘀、阴虚/阳虚、痰/湿/水饮/津亏中选择需要鉴别的病理要素。
5. **组合证候**：只有多个相互支持的症状、病程与舌脉线索同时存在时，才能形成主证、兼证或备选证候。
6. **鉴别与反证**：每个候选都写支持点、反证或不符合点、缺失信息和最能区分相似方向的问题。
7. **动态复核**：说明哪些新症状、标准复测或舌脉资料会改变当前判断。

C 级可以扩展“待辨方向”，但应按数据域分组。例如代谢域可细分脾气虚、脾阳虚、痰湿、湿热、食积或胃热；不能把这些斜线名称拼成一个已经成立的复合证型。

## 常见证候知识与鉴别

以下是从参考病例写法中提炼的候选轴，不是“指标到证型”的自动映射。优先使用用户明确提供的症状；设备或疾病风险域只能决定应该追问哪一轴。

| 候选方向 | 支持线索（需实际提供） | 主要鉴别/反证 | 可解释的治法方向 |
|---|---|---|---|
| 脾气虚、脾虚湿困 | 食少、餐后腹胀、便溏或黏滞、乏力困重、面色少华，舌淡胖或有齿痕 | 若口苦口黏明显、便臭黏、舌红苔黄腻，更偏湿热；只有 BMI/血脂风险不足以定证 | 健脾益气、运化水湿 |
| 痰湿内阻 | 体重增加伴身重、胸闷痰多、口黏、头重困倦、苔厚腻 | 无痰湿症状、舌苔薄净时证据弱；肥胖或脂肪肝不能单独证明痰湿 | 健脾化痰、利湿，配合饮食和活动管理 |
| 肝郁气滞 | 情绪波动相关的胸胁/胃脘胀、叹气、咽中不利、经前不适、睡眠受情绪影响 | 持续高热、明显器质性疼痛或固定刺痛需另查；焦虑评分本身不能证明肝郁 | 疏肝理气、调畅情志 |
| 心脾两虚、心神失养 | 心悸、健忘、多梦易醒、疲乏、食欲差、面色淡，劳累后加重 | 烦热盗汗、口干舌红更偏阴虚；胸痛晕厥先走临床急症路径 | 益气养血、健脾宁心 |
| 气阴两虚、阴虚内热 | 乏力气短与口干、潮热盗汗、五心烦热、舌红少津并见 | 明显畏寒、便溏、水肿更偏阳虚；血糖风险不能自动等于消渴或阴虚 | 益气养阴、生津，避免过度温燥 |
| 脾肾阳虚 | 畏寒肢冷、腰膝酸软、清晨腹泻、夜尿、水肿、精神不振，舌淡胖润 | 口渴喜冷、便秘、舌红少津不支持；低活力评分不能单独证明阳虚 | 温养脾肾、助阳化湿，但需排除贫血、甲状腺等问题 |
| 血瘀、痰瘀互结 | 固定刺痛、夜间加重、唇舌暗或瘀点、肢体麻木，兼胸闷痰多时考虑痰瘀 | 只有心血管模型风险不能定血瘀；急性胸痛、神经缺损先急诊 | 活血通络仅作面诊讨论；抗凝用药者避免自行用活血药 |
| 肝阳上亢 | 反复头胀痛、眩晕、耳鸣、急躁、面红目赤，常见舌红脉弦有力 | 无相关症状或仅一次血压估算不支持；眩晕也需排除耳源、神经和药物原因 | 平肝潜阳，先规范确认血压和危险症状 |
| 湿热内蕴 | 口苦口黏、身重、脘痞、便黏臭或尿黄、舌红苔黄腻 | 畏寒、清稀便、舌淡润更偏寒湿/阳虚；肝酶或代谢风险不能单独定湿热 | 清利湿热，避免自行长期苦寒攻伐 |

不要把上表全部展示给用户。A/B 级只选主方向与一个备选；C 级按现有资料覆盖数据域，每组选择 2–5 个确有鉴别价值的子方向，并说明怎样区分，不能只增加名称数量。

## 设备与检查数据的 C 级辨证路由

- **体型、血糖、血脂、脂肪肝、整体代谢域**：鉴别 `脾气虚/脾阳虚`、`痰湿`、`湿热`、`食积` 与 `胃热`。先用食欲、餐后腹胀和便溏看脾虚；用畏寒喜暖看阳虚；用身重痰多、苔厚腻看痰湿；用口苦尿黄、苔黄腻看湿热；用嗳腐吞酸或消谷善饥区分食积与胃热。设备百分比只表示该域需要确认，不说明已经异常或已成某证。
- **焦虑、压力、睡眠、活力、HRV 域**：鉴别 `肝郁气滞/肝郁化火`、`心神不宁/痰热扰心`、`心血虚/心脾两虚` 与 `心阴虚`。询问情绪诱因、胸胁胀、叹气、口苦急躁、心悸、多梦、盗汗、食欲和疲乏。HRV 不能替代脉诊，心理评分不能证明肝郁。
- **血压、心率、心血管风险域**：鉴别 `肝阳偏亢/肝肾阴虚`、`痰浊/血瘀`、`心气虚/心阳虚` 与 `气血两虚`。先用标准设备确认，再询问头痛眩晕耳鸣、急躁、胸闷痰多或固定刺痛、心悸气短、畏寒、自汗、面色和舌色。
- **呼吸、血氧与活动耐量域**：鉴别 `肺气虚`、`肺阴虚`、`痰湿犯肺` 与 `卫表不固`。血氧异常或明显呼吸困难先走现代医学评估，再询问咳嗽痰量、口咽干燥、自汗易感和活动后气短。
- **水分、浮肿和泌尿域**：鉴别 `脾阳虚`、`肾阳虚`、`水湿内停` 与泌尿系统疾病。询问晨起或下肢浮肿、畏寒、腰膝、夜尿和尿量变化。
- **过敏、鼻咽和皮肤域**：讨论 `特禀质`、`肺卫不固`、`风燥` 或 `湿热` 等方向，同时记录明确诱因和严重过敏史。
- **仅有质量差或无有效数据**：不列候选证型，只写信息不足、需重测和需要补充的四诊问题。

## 四诊与高价值补充信息

不要一次询问完整问卷。只选择会改变当前判断的 3–5 项：

- 寒热：怕冷还是怕热，是否发热、潮热、手足冷热；
- 汗与口渴：自汗/盗汗、口渴程度、偏好冷饮或热饮；
- 脾胃与水液：食欲、餐后胀、恶心、口黏、浮肿；
- 二便：大便稀/干/黏滞、夜尿或尿量变化；
- 睡眠与精力：入睡、早醒、多梦、白天疲乏及其时间规律；
- 疼痛：位置、胀/刺/灼/隐痛、固定或游走、活动和按压影响；
- 女性相关：月经、孕产和围绝经情况，仅在与问题相关时询问；
- 舌脉：舌照需自然光、无滤镜并说明近期饮食染色；脉象原则上由合格临床人员判断。

## 内容覆盖与自然表达

下面三层是推理覆盖范围，不是普通诊聊必须显示的固定标题。普通对话第一句直接写判断且不加“核心判断/结论”标签，只保留最多 2 个会改变行动的西医原因和 1 个最相关的中医待辨方向；两者压缩在同一短段，不各写一套小报告，也不列备选证型。用户明确要求详细中医分析时，才展开组内细分方向、辨证路径和鉴别问题。删除寒暄、复述、正常项巡检、证型目录、通用养生常识和结尾总结。

### 先说清当前判断

- **结论先行**：先写临床紧急程度、最值得处理的问题和资料局限。
- **西医视角**：区分已确认发现、待排疾病和设备/模型估算。
- **中医补充视角**：A/B 级写 `证候倾向` 而非确诊证型；C 级写 `资料型待辨方向`。不能只用“信息不足”一句话结束有可用健康域的报告。

示例措辞：`现有“餐后困倦、腹胀、大便偏溏”等线索可能与脾气不足、湿困的方向相符；但缺少舌脉、怕冷/口渴及病程资料，不能据此定证。`

### 再解释依据和可能机制

- **西医机制链**：`事实 → 常见生理/病理机制 → 需要排除的原因 → 如何确认`。
- **中医病机线索**：`症状组合与病程 → 可能的气血津液/脏腑证候方向 → 支持与不支持信息 → 面诊辨别点`。
- 明确两条链不是互译。例如代谢异常可以与某些痰湿线索同时出现，但代谢指标本身不能证明痰湿。

### 最后给出下一步

按以下顺序给建议：

1. 红旗症状与急诊规则；
2. 临床复测、确认检查和首诊科室；
3. 双方通常都认可且风险较低的行动，例如规律睡眠、适量活动、减少烟酒和过量精制糖、记录症状与测量趋势；可按候选方向补一条普通饮食或作息原则，但不要把食疗写成药方；
4. 若用户希望继续中医评估，说明应向合格中医师提供哪些病程、舌脉、用药和检查资料；
5. 可解释 `健脾化湿`、`疏肝理气` 等治法术语的含义，但仅作为面诊讨论方向，不据不完整信息给方药、剂量或疗程。

普通食物建议应保持日常饮食尺度，避免把食疗写成变相处方；糖尿病、肝肾疾病、食物过敏、孕哺期和儿童需要个体化审核。

## 调养建议的完整结构

有用户要求调养或正式报告时，按 `饮食、起居、运动、情志、穴位保健` 五个维度组织。先写各方向都适用的低风险基础措施，再写带条件的方向性建议：

- **通用基础**：规律三餐和作息、食物多样、减少烟酒/含糖饮料/过量甜腻油炸、避免久坐、在可耐受范围内逐步活动并记录变化。
- **气虚/气血不足待辨**：保证营养与恢复时间，运动循序渐进，避免长期空腹和每次都练到筋疲力尽。
- **阳虚待辨**：注意腰腹足部保暖，以熟食温食为主；伴口干便秘、烦热或血压不稳时不自行温补。
- **阴虚待辨**：减少熬夜、酒和辛辣刺激，避免高温下过度运动，不自行叠加温燥补品。
- **痰湿/代谢方向待辨**：重点放在总能量、甜食、油炸、酒、夜宵和活动管理，不依赖单一“祛湿食物”或极端断食。
- **湿热待辨**：减少酒、烧烤、油炸、辛辣和过甜食物，不自行长期使用苦寒清热或泻下产品。
- **肝郁/心神不宁待辨**：固定睡眠窗口，安排户外活动、舒缓运动、呼吸放松、兴趣与社会支持；持续焦虑抑郁或失眠需专业评估。
- **血瘀/痰瘀与心血管方向待辨**：避免久坐并在医学评估允许范围内活动；抗凝/抗血小板用药者不得自行使用丹参、三七、红花等所谓活血产品。
- **特禀/过敏方向待辨**：记录并减少明确过敏原；哮喘或严重过敏遵循医生应急方案，不以食疗或按揉替代。

穴位内容仅限轻柔按揉的保健选择，可提及足三里、内关、神门、印堂或太冲。写明每处约 1–2 分钟、轻微酸胀即止、不得疼痛或留瘀青；皮肤破损、孕期、出血风险或严重基础疾病应先咨询专业人员。不得提供自我针刺步骤。

## 禁止机械映射

以下只能作为需要结合症状继续判断的联想，不能直接下结论：

- 血糖或糖尿病风险升高 ≠ 自动等于 `消渴`；
- 脂肪肝、肥胖或血脂异常 ≠ 自动等于 `痰湿`；
- 血压升高 ≠ 自动等于 `肝阳上亢`；
- 失眠或焦虑评分升高 ≠ 自动等于 `心火旺` 或 `肝郁`；
- 肾功能指标异常 ≠ 自动等于 `肾虚`；
- 单张舌照、一次脉象或体质问卷 ≠ 完整证候诊断。

## 干预安全边界

- 不开具、停用或调整处方药，也不提供个体化中药方、药味组合、剂量、煎服法或疗程。
- 不因“天然”推断安全。中草药可能有成分差异、污染、肝肾毒性或与抗凝药等发生相互作用；孕哺期、儿童、老年人、过敏者和肝肾功能异常者尤其需要专业审核。
- 针灸应由具备相应资质的人员使用无菌、规范方法实施；不提供自我针刺或高风险穴位操作。
- 若用户已使用中药或保健品，记录产品全名、成分、剂量、频次和开始时间，建议同时告知医生、中医师和药师。
- 不用中医调护掩盖警示症状，也不承诺“根治”“排毒”或确定疗效。

## 证据与表述

涉及具体疗法时，按具体适应证检索当前指南或系统综述，不把“中医药总体历史悠久”当作某项疗法有效的证据。区分：

- **记录事实**：用户或报告明确提供；
- **临床一般知识**：需结合个体情况确认；
- **中医理论解释**：用于组织证候线索，不等于现代医学机制证据；
- **疗效证据**：只针对具体干预、具体疾病和具体结局陈述，并说明证据质量与局限。

权威起点：

- WHO, *Global traditional medicine strategy 2025–2034*：强调以证据、安全、监管和以人为本的方式整合传统医学。https://www.who.int/publications/i/item/9789240113176
- NCCIH, *Traditional Chinese Medicine: What You Need To Know*：说明针灸、太极和中草药证据不一，并提示污染、不良反应和不当针刺等风险。https://www.nccih.nih.gov/health/traditional-chinese-medicine-what-you-need-to-know
- 《中华人民共和国中医药法释义（十二）》：说明辨证需综合望、闻、问、切资料。https://www.yunfu.gov.cn/zyyj/zwgk/bmwjyjd/content/post_1493418.html

使用前检查来源是否有更新；具体疾病的阈值、诊疗和用药仍以适用地区的现行临床指南为准。
