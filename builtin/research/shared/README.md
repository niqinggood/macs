# Scholar Skills — Shared Resources

## Academic Search URLs

| Source | URL Pattern | Auth |
|--------|------------|------|
| arXiv RSS | `https://rss.arxiv.org/rss/CATEGORY` | None |
| PubMed E-utils | `https://eutils.ncbi.nlm.nih.gov/entrez/eutils/` | None |
| CrossRef API | `https://api.crossref.org/works?query=` | None |
| Semantic Scholar | `https://api.semanticscholar.org/graph/v1/paper/search?query=` | None |
| Google Scholar | `https://scholar.google.com/scholar?q=` | May block |

## Citation Styles

| Style | In-text | Bibliography |
|-------|---------|-------------|
| APA 7 | (Author, Year) | Author, A. (Year). Title. *Journal*, Vol, Pages. |
| MLA 9 | (Author Page) | Author, First. "Title." *Journal* Vol.Issue (Year): Pages. |
| Chicago | (Author Year, Page) | Author, First. "Title." *Journal* Vol, no. Issue (Year): Pages. |
| Vancouver | [1] | 1. Author A. Title. *Journal*. Year;Vol:Pages. |
| IEEE | [1] | [1] A. Author, "Title," *Journal*, vol. X, pp. XX, Year. |
