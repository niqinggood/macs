# 现代指标到中医候选病机

用于用户提供化验、体检、影像、可穿戴设备或健康机器报告，并要求从中医角度归纳情况、给出保健、食疗或足部调护时。

**缺少报告参考范围时的停止规则**：只复述用户给出的原始数值和影像结论，明确不判异常程度、不补现代诊断或检查项目，并请接诊医生结合完整报告评估。中医只给一个低把握候选和三个症状追问；不得从本文件下文摘取固定阈值、疾病名称、检查组合、复查时间或量化生活目标。

## 1. 输出目标

完成“关联推演”，而不是机械翻译：

`现代医学事实 → 指标组合 → 中医候选证素/病机 → 症状与舌象分支 → 低风险调护 → 复测/随访`

报告推演允许回答“整体更偏向什么中医方向”，但结论名称使用 `报告推演方向`、`候选病机` 或 `待辨分支`。只有现代指标时属于 C 级；补齐相互印证的症状、病程和舌象后才可升级到 B 级证候倾向。

## 2. 先审数据，再谈中医

逐项区分：

- **可直接理解的测量值**：血压、心率、体温、身高、体重、BMI、腰围、实验室检验等；仍需核对单位、测量方法、时间和参考范围。
- **可解释但必须看上下文的结果**：影像结论、医生诊断、已注明算法和阈值的风险分层。
- **不可自行解释的值**：没有单位、参考范围或算法说明的“健康分、风险分、代谢年龄、睡眠指数、压力指数、信噪比”等。只列出原值并注明待确认，不能擅自判高低、好坏或用于辨证。
- **明显异常但来源可疑的数据**：先建议用标准设备或医疗机构复测，不围绕可疑数据建立病机。

现代医学风险分流始终先于中医归纳。指标提示急症、严重异常或需要规范诊疗时，先给复测、就医或检查建议；中医调护不能替代降压、降糖、调脂、抗感染、抗凝等规范治疗。

报告解释不等于远程诊疗：部分指标只可描述为风险线索，不足以直接诊断代谢综合征、糖尿病或疾病分期。不要给西药剂量、调量、疗程；不要用记忆中的统一正常值覆盖化验单参考范围。若要引用精确阈值、复查间隔或减重/营养目标，必须在当次核实适用于该人群的当前权威来源。

**代谢报告的强制表达边界**：当用户提供空腹血糖、甘油三酯、ALT 的数值与报告上限，并同时提供脂肪肝影像时，只能先说“这些项目按该报告参考范围被标为异常，需要结合复测、病史和其他指标整体评估”。资料不足时不得写“已处于空腹血糖受损”“未达到糖尿病切点”“高概率代谢综合征/胰岛素抵抗”“典型某型血脂异常”或直接确定脂肪肝病因。不得凭记忆增加复查周数、运动分钟数、腰围/BMI 阈值、足浴温度或检查套餐；需要具体医学计划时交给接诊医生或在当次核实权威指南。

## 3. 用指标聚类，不用单项贴证型

以下是候选方向生成规则，不是“数值—证型”对照表。

### 体重与代谢聚类

当 BMI/腰围升高，并与甘油三酯、脂肪肝、血糖异常或久坐等共同出现时，只能把 `痰湿、湿浊待辨` 作为低置信候选背景，不能称“典型痰湿表现”。报告项目不是中医证据；继续用症状分支：

- 身体困重、脘腹痞满、口黏、大便黏滞、舌体偏胖且苔白腻，支持痰湿/湿浊；
- 易饥、口渴、口苦口臭、便秘或黏滞、尿黄、舌红苔黄腻，才把湿热或胃热列为主要分支；
- 食少腹胀、便溏、乏力、畏寒、浮肿、舌淡胖，才把脾虚或脾肾阳虚列为主要分支；
- 胸胁胀、善太息、情绪相关进食、失眠或月经不调，才把气郁列为主要分支。

肥胖本身只支持进入上述分支辨别，不能单独证明“痰湿体质”。国家卫生健康委《肥胖症诊疗指南（2024年版）》和《成人肥胖食养指南（2024年版）》可作为当前中国成人肥胖分型与辨证施膳的权威入口：<https://www.gov.cn/zhengce/zhengceku/202410/P020241020715873679737.pdf>。

### 血糖聚类

空腹血糖、糖化血红蛋白或糖耐量异常首先按现代医学标准确认。不能由“血糖高”直接写成消渴、阴虚或湿热：

- 多饮、多尿、多食、体重下降、口咽干燥等存在时，才进入消渴相关病机辨别；
- 超重、困重、口黏、脘痞、苔腻等组合更支持痰湿/湿热分支；
- 乏力、自汗、口干、气短等组合可考虑气阴不足分支；
- 没有症状时只写代谢异常背景，不强立中医病名。

任何食疗都不能替代糖尿病诊疗，也不能暗示某种食物可以降糖。若已确诊糖尿病，食物总量、碳水化合物和用药低血糖风险优先于中医食性。

### 血脂与脂肪肝聚类

血脂异常、脂肪肝、中心性肥胖和久坐组合只能生成 `痰浊/湿浊待辨` 假设；真正提高支持度仍需困重、胸脘痞满、痰多、便黏或可靠苔腻等症状组合。若同时有固定刺痛、唇舌紫暗、瘀点等才可讨论 `血瘀兼夹`；血管病史本身不等于血瘀。肝酶升高不能直接解释为肝火、肝郁或湿热，必须先按现代医学评估原因。

国家卫生健康委食养指南可用于高脂血症的现代营养约束和常见中医分型背景：<https://www.nhc.gov.cn/wjw/c100378/202301/7faed9993c9b45aea158c5335346f282/files/1732844468018_41219.pdf>。

对“血糖偏高 + 甘油三酯偏高 + ALT 偏高 + 脂肪肝 + 饭后困/腰围增加”这类组合，中医可把痰湿/湿浊列为首个候选，但置信级通常为较低到中等：真正支持证候的是饭后困、腰围变化等症状体征，报告异常只提供代谢背景。口苦口黏、便黏尿黄会提高湿热分支；便溏怕冷、饭后胀乏力会提高脾虚夹湿分支。没有标准体质问卷和长期信息时，不完成体质判定。

### 血压聚类

血压升高不能直接等于肝阳上亢：

- 头胀头晕、面红、急躁、口苦、耳鸣、舌红等才支持肝阳/肝火分支；
- 头重昏蒙、胸闷恶心、困倦、苔腻等支持痰湿分支；
- 固定刺痛、唇舌暗或瘀点支持血瘀兼夹；
- 腰膝酸软、耳鸣、潮热或畏寒等才进入肝肾不足分支。

单次设备读数先规范复测。报告推演不得给停换降压药指令，也不得把按揉、足浴或食疗描述成降压治疗。

### 血常规、肾功能与水肿聚类

- 血红蛋白低不自动等于血虚；结合面色少华、头晕心悸、乏力、甲色淡、舌淡等才支持血虚候选，同时优先排查失血、缺铁、慢性病等原因。
- 肌酐、尿蛋白异常不自动等于肾虚；先做肾脏专科风险分流。水肿、尿少、畏寒、乏力等可参与脾肾气阳不足与水湿分支，但不能替代肾病诊断。
- 尿酸高不自动等于湿热。只有急性关节红、肿、热、痛等症状时才讨论湿热痹阻候选；无症状高尿酸以现代管理为主。

### 睡眠、压力与情绪聚类

只有量表名称和数值、却没有量表范围与方向时，不解释高低。先获取真实表现：入睡困难、早醒、多梦、心悸、胸闷叹气、烦热盗汗、食欲和二便，再鉴别肝郁、心脾不足、阴虚火扰、痰热扰心等方向。机器“压力分”不能单独证明气郁。

## 4. 归纳规则

每次报告分析只保留：

1. **一个核心方向**：解释最多、最可靠指标组合的候选病机；
2. **一个分支方向**：如果成立会明显改变食疗、足部调护或就医建议；
3. **三到五个确认问题**：围绕寒热、口渴食欲、二便、困重/乏力、睡眠情志和舌苔选择最有区分力的问题；
4. **反证**：明确哪些事实出现时需要改判。

推荐表述：

> 这组指标在中医框架下首先提示“痰湿/湿浊待辨”，依据是中心性肥胖与多项代谢异常形成了同一指标群；目前还不能确定是偏寒湿、湿热还是脾虚为本。若同时有身体困重、口黏、脘腹痞满、大便黏滞和苔腻，支持度会提高；若以口渴易饥、便秘、舌红苔黄为主，则更偏湿热/胃热分支。

不要把候选方向并列成“痰湿 + 湿热 + 气郁 + 心脾两虚 + 气虚血瘀”的清单。

## 5. 从归纳到保健与食疗

先给所有候选方向都适用的底层方案，再给分支化选择。普通食物建议必须服从已确诊疾病、药物、过敏、能量和营养需求。

- **痰湿/湿浊待辨**：重点是减少含糖饮料、酒、油炸、夜宵和过量精制主食，规律活动；食物可从全谷杂豆、菌菇、绿叶菜、冬瓜及足量优质蛋白中选择。不要把薏苡仁、荷叶、山楂等写成降脂降糖药；妊娠、肾病、胃肠敏感或正在用药者先个体化核对。
- **湿热/胃热分支**：在上述基础上减少酒、辛辣烧烤和高糖高脂食物；是否适合偏凉食物取决于胃肠耐受、季节和基础病，不要求大量冷饮、生食或单一“祛湿茶”。
- **脾虚/气虚分支**：规律少量进餐，选择易耐受的熟食与足量蛋白，避免长期极低热量、只吃生冷果蔬或用腹泻追求减重；山药、莲子、白扁豆等只能作为普通食物搭配并计入总能量/碳水。
- **气郁分支**：把规律运动、睡眠节律、情绪性进食记录和呼吸放松放在所谓疏肝食物之前；不以代茶饮替代心理或睡眠问题评估。
- **阴虚/津亏分支**：无心肾限水时保持正常饮水，减少酒精和刺激性食物；不要因“滋阴”而大量摄入糖分高的甜汤或膏方。
- **血瘀兼夹**：以戒烟、规律活动和规范心血管管理为先；正在用抗凝/抗血小板药或有出血风险时，不自行使用活血药材、强力按摩、刮痧或拔罐。

给出一到三项最匹配的选择即可，同时说明观察指标，例如体重/腰围趋势、按医嘱记录的血压、睡眠和大便变化。没有本轮核实的指南或用户医嘱，不自行规定测量频率。不要用“排湿反应”解释腹泻、头晕或皮疹。

## 6. 足部调护

足浴和足部按揉只定位为放松、睡前仪式或轻度局部舒适措施，不宣称通过足底反射区治疗肝、肾、血压、血糖或脂肪肝。NCCIH 对足底反射疗法的结论是多数用途证据不足：<https://www.nccih.nih.gov/health/reflexology>。

### 可给的低风险方案

- 足部皮肤完整、温痛觉正常、没有明显循环障碍、急性红肿热痛或严重水肿时，才可把清水温足浴作为可选放松方式；不凭记忆给温度和时长，结束后保持干燥并留意皮肤异常。
- 可给轻柔足底、足弓和踝周按揉或踝泵活动，以舒适放松为度；出现疼痛、麻木加重、头晕、心悸、皮肤发红或水疱立即停止。
- 穴位按揉最多选一到两个与当前症状相关、位置容易辨认且远离破损处的点，写明“舒适力度、短时按揉、不能代替治疗”。妊娠、抗凝/出血倾向、感觉减退和局部病变时不提供自行按揉方案。
- 不生成中药足浴配方和克数，不提供肝、肾、脾、胰等足底反射区。报告中的脂肪肝、血糖、血脂或肝肾指标不能成为反射区足疗的理由。

### 不自动推荐足浴/足疗的情况

- 已确诊糖尿病，尤其合并周围神经病变、足部感觉减退、外周动脉疾病、既往足溃疡或截肢；
- 足部破损、水疱、溃疡、感染、真菌急性炎症、明显红肿热痛、急性痛风或不明原因肿胀；
- 明显静脉血栓风险、严重心肾功能不全所致水肿、无法可靠感知水温或无法自行检查足部；
- 对拟用泡洗材料过敏，或无法确认外用药成分和浓度。

美国 NIDDK 建议糖尿病患者用温水清洗而不要浸泡足部，并强调每日检查破损：<https://www.niddk.nih.gov/health-information/diabetes/overview/preventing-problems/foot-problems>。中国国家卫生健康委也提醒糖尿病足患者不要自行随意泡脚：<https://www.nhc.gov.cn/xcs/c100122/202412/c6df3c35863f4981907ca27c7fdaa830.shtml>。遇到此类人群，优先给足部检查、合适鞋袜和线下足病/内分泌评估，而不是泡脚配方。糖尿病合并感觉减退、水疱、破损或溃疡时明确不浸泡、不按摩病变足，不追加“评估后可用淡药水”的方案。

## 7. 报告型回答模板

按用户需要控制长度，建议顺序是：

1. **先给结论**：现代医学最该处理的事项 + 一个中医报告推演方向与置信等级；
2. **说明归纳链**：哪些指标形成同一聚类，为什么提示该候选病机，什么数据不能解释；
3. **做分支鉴别**：三到五个关键症状/舌象问题，说明不同答案如何改判；
4. **给方案**：基础保健 + 分支化食疗 + 足部调护或其禁忌；
5. **定复评点**：标准设备复测、必要检查、症状记录、停止条件和就医时限。

不要先输出长篇证型百科，也不要在用户尚未回答分支问题前给彼此相反的寒凉与温补方案。
