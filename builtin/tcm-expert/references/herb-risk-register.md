# 重点药材风险登记

这是审方触发器，不是完整毒性数据库。出现下列成分时，必须查询使用地现行药典、说明书和监管警示，核对基原、炮制、剂量、疗程、并用药和肝肾功能；不得凭本文件给出可执行剂量。

## 重点品种

| 品种/类别 | 主要审查点 | 必问信息 |
|---|---|---|
| 何首乌及制首乌 | 已有肝损伤安全信号；炮制不能消除所有风险 | 产品全名、炮制、用途、疗程、肝病、黄疸/深色尿 |
| 乌头、附子、草乌、川乌 | 炮制和煎煮要求严格，错误使用可致严重心律与神经毒性 | 饮片基原、炮制、先煎、心律病、麻木心悸呕吐 |
| 含马兜铃酸风险品种及混淆品 | 肾毒性与致癌风险，基原混淆尤其危险 | 规范名、拉丁基原、厂家批号、肾功能、尿检 |
| 雷公藤 | 生殖、肝肾、骨髓及免疫相关严重风险 | 妊娠计划、血常规、肝肾、感染、免疫抑制药 |
| 朱砂、雄黄等矿物药 | 汞/砷等暴露与蓄积风险，不能长期或随意内服 | 制剂、来源、疗程、肝肾、儿童/妊娠 |
| 麻黄 | 心率、血压、失眠和刺激作用风险 | 高血压、心律、甲亢、焦虑失眠、其他兴奋剂 |
| 甘草及含甘草复方 | 长期/大量可能涉及水钠潴留、低钾、血压和药物相互作用 | 疗程、血压、水肿、钾、利尿剂/地高辛等 |
| 苦杏仁、桃仁等含氰苷品种 | 品种、炮制和剂量错误可中毒 | 是否生用、儿童、来源、恶心头晕呼吸异常 |
| 土三七等易与三七混淆品 | 品种混淆可带来严重肝损伤风险 | 实物标签、基原、网购/自采、肝功能 |
| 细辛及同名混淆品 | 基原、药用部位与马兜铃酸控制要求 | 现行药典品种、部位、来源和检验信息 |

## 复方和产品层面的风险

- 同时使用汤剂、中成药、代茶饮和保健品时，展开全部成分，检查重复甘草、麻黄、附子、何首乌等。
- “纯天然、祖传、秘方、药食同源”不是质量证明。标签不全、无批准/备案信息、散装粉末、跨境网购或自采品种均提高不确定性。
- NCCIH 提醒部分中草药产品可能有错药、未声明药物、重金属、农残或其他污染：<https://www.nccih.nih.gov/health/traditional-chinese-medicine-what-you-need-to-know>。
- 相互作用证据可能有限，但华法林、地高辛、抗癫痫、免疫抑制、抗肿瘤和降糖药等窄治疗窗/高风险药物应采取更谨慎策略：<https://www.nccih.nih.gov/health/providers/digest/herb-drug-interactions>。

## 审查输出

按 `成分身份 → 已知风险 → 当前用户放大因素 → 需要核对的权威资料 → 立即停止/就医信号 → 与开方医师或药师讨论的问题` 输出。

出现黄疸、深色尿、明显少尿、晕厥、严重心悸、抽搐、呼吸困难、面唇舌肿胀或明显出血时，先按急症/严重不良反应处理，不继续辨证，也不建议减量再试。
