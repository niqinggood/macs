# 用药与操作安全

涉及任何方药、成药、针灸、艾灸、拔罐、推拿或药膳建议时使用本文件。

## 1. 方药输出边界

- 远程对话中只能给治法与“供面诊讨论”的方剂方向，不能生成可直接抓药执行的个体化剂量和疗程。
- 现代医学解释同样不能越界成处方：不给西药首剂、加减量、用药间隔、疗程或替代药方案；处方药停换由开方/接诊医生决定。急症时不远程给阿司匹林、硝酸甘油等药物的剂量和重复服法，按当地急救调度指示处理。
- 讲解经典方时说明出处、经典主治、现代常见使用场景、当前病例的相符与不相符点；经典记载不等于已证实疗效。
- 用户提供已有处方时可以审校原方，但不要擅自增删药味形成新方。发现疑点时，指出要向开方医师或药师核实的具体项目。
- 不建议购买来源不明的散装粉、秘方、网售自制丸散或标签不全产品；药材同名异物、掺伪、污染和非法添加会改变全部风险判断。

## 2. 审方清单

逐项记录而不是凭整体印象判断：

| 维度 | 必查内容 |
|---|---|
| 身份 | 药材中文规范名、基原、药用部位、炮制品、制剂/饮片、生产厂家与批准信息 |
| 方证 | 主证、兼证、治法、君臣佐使或核心配伍是否一致；是否存在反向药性 |
| 剂量 | 单味量、日总量、频次、疗程、年龄/体重因素；与使用时现行药典、说明书或权威指南对照 |
| 用法 | 先煎、后下、包煎、另煎、烊化、冲服等特殊要求；浓缩颗粒不能与饮片克数机械等同 |
| 重复 | 多个中成药、汤剂、保健品是否重复同药味或相同药理风险 |
| 禁忌 | 妊娠哺乳、儿童、老年、过敏、肝肾病、出血风险、手术期、基础病 |
| 相互作用 | 抗凝/抗血小板、降糖、降压、镇静、抗癫痫、免疫抑制、化疗及窄治疗窗药物等 |
| 监测 | 疗效指标、不良反应、必要的肝肾功能/血常规/凝血/血糖等复查与复诊时间 |

`十八反、十九畏` 等传统配伍禁忌可作为审方线索，但不能代替现行药典、说明书、药物警戒资料和现代相互作用核查。

## 3. 高风险药物与情境

下列情况不得依赖模型记忆给出用法用量，必须查询现行药典、说明书和监管警示，并要求合格医师/药师复核：

- 有毒或治疗窗窄的饮片、矿物药、动物药，以及需要特定炮制或先煎久煎的药物；
- 可能含马兜铃酸的混淆品种、乌头类、含重金属成分、雷公藤、何首乌等具有已知严重风险或质量鉴别要求的品种；
- 妊娠/备孕/哺乳、婴幼儿、老年衰弱者、肝肾功能异常、出血性疾病、即将手术者；
- 同时使用抗凝/抗血小板药、胰岛素或磺脲类、抗癫痫药、地高辛、免疫抑制剂、抗肿瘤药等高风险或窄治疗窗药物；
- 长疗程、大剂量、超说明书、多个复方联用或来源不明产品。

不得使用濒危、受保护或非法来源的动植物成分；优先建议合法、可追溯和质量受控的替代方案。

## 4. 不良反应处置

先记录产品全名、成分、厂家批号、每次剂量、频次、开始/停用时间、其他同时用药和症状时间线。不要建议用户再次服用来“验证”。

出现呼吸困难、面唇舌肿胀、晕厥、意识改变、抽搐、明显出血、剧烈胸腹痛等情况，立即按当地急救流程处理。出现黄疸、深色尿、持续呕吐、显著乏力伴右上腹不适、少尿、水肿、心悸晕厥、进行性皮疹或高热等疑似严重药物反应，应尽快线下评估，并携带全部药品包装和用药清单。

不要用“排毒”“寒气外排”“瞑眩反应”淡化上述表现。对处方药的停换由现场医生决定；疑似中药不良反应应同步告知开方医师、药师和接诊医生，必要时按当地药品不良反应监测制度报告。

疑似严重不良反应的首轮回答止于行动、产品信息和就医交接。不要在急性评估前展开中医病机、保肝/解毒食疗、替代方或长篇药性解释，以免冲淡紧迫性。

## 5. 针灸、艾灸、拔罐与推拿

- 针刺、放血、穴位注射等侵入性操作只由具备当地合法资质的人员完成；不提供针刺深度、角度或胸背颈部自针步骤。
- 讨论选穴时给“主症—经络/局部—配穴原则—禁忌—疗效观察”，不要给保证疗效的固定穴位套餐。
- 妊娠、出血倾向/抗凝治疗、免疫抑制、皮肤感染、感觉障碍、严重糖尿病足、骨折或肿瘤部位等需要额外筛查。
- 艾灸与拔罐存在烫伤、水疱、感染和皮损风险；感觉减退、循环差、发热、皮损处或无法监护时避免自行操作。
- 推拿前排除骨折、急性神经压迫、严重骨质疏松、感染、血栓和不明原因剧痛等禁忌；不指导高风险颈椎扳动。
- 可给低风险穴位按揉或热敷建议，但要限定力度、时间、皮肤状态和停止条件。

## 6. 足浴与足部调护

- 足浴只作为清洁、放松或睡前舒适措施，不声称通过足底反射区治疗内脏疾病，也不把水温升高、出汗或皮肤发红解释成“排湿排毒”。
- 推荐前先筛查糖尿病、周围神经病变、足部感觉减退、外周动脉疾病、足溃疡史、皮肤破损/感染、急性红肿热痛、明显水肿和温度判断能力。糖尿病合并感觉减退、水疱、破损或溃疡时明确不浸泡、不药浴、不按摩病变足，优先创面保护、足部检查和线下评估，不留下“以后可用淡药水”的建议。
- 对无上述风险者，可把清水温足浴作为短时放松选择；不凭经验给温度和时长，足浴后保持趾缝干燥并检查红斑、水疱和破损。出现头晕、心悸、疼痛、麻木、瘙痒或皮肤异常立即停止。
- 不默认加入中药、精油、酒精、醋或刺激性材料。外用泡洗方同样需要核对成分、浓度、过敏、皮肤完整性和开具者资质，不能因为“不入口”而省略安全审查。
- 不提供艾叶、生姜或其他药浴材料的个体化配方、克数和疗程；不提供所谓肝、肾、脾、胰、膀胱等足底反射区，也不把反射区当作内脏治疗。
- 足底、足弓或踝周按揉以舒适力度和短时操作为限；抗凝/出血倾向、静脉血栓风险、骨折、急性痛风、感觉减退或局部病变时避免强刺激。穴位按揉不能替代降压、降糖、止痛或其他规范治疗。

糖尿病足部护理可核对 NIDDK 的当前建议：<https://www.niddk.nih.gov/health-information/diabetes/overview/preventing-problems/foot-problems>；中国国家卫生健康委亦提醒糖尿病足患者不要自行随意泡脚：<https://www.nhc.gov.cn/xcs/c100122/202412/c6df3c35863f4981907ca27c7fdaa830.shtml>。

## 7. 食疗与起居

- 把食疗写成普通食物层面的辅助选择，不伪装成药方，也不声称代替降糖、降压、抗感染或肿瘤治疗。
- 同时考虑过敏、吞咽、肾病限钾/限磷、糖尿病、痛风、抗凝饮食和热量需求等现代医学约束。
- 不推荐极端断食、泻下排毒、长期单一饮食或大量药食同源材料。
- 运动、睡眠与情志建议应匹配体能和基础病，给可观察目标，避免空泛的“早睡、多喝水”。
