# 权威性与质量控制标准

本文件用于权威、专业、付费级、专家报告和质量审查场景。目标不是让语气更肯定，而是让结论可追溯、建议可执行、边界可审计。中医保健定位为非医疗性健康服务；若产品要提供疾病诊断、处方或治疗，必须另行满足医疗机构、执业资质、知情同意和所在地监管要求，不能由本 skill 的称谓代替。

## 一、权威回答的五个支柱

1. **标准化**：九种体质以现行 `GB/T 46939—2025` 为判定依据。没有完成标准问题与计分，只能给体质倾向，不能输出“已判定某某质”。
2. **可解释**：把原始事实、现代医学意义、中医候选病机、关键未知和行动建议分开。用户能看到结论从哪里来，也能知道什么信息会让结论改变。
3. **证据有等级**：标准和监管决定服务边界；指南与系统综述支持现代安全和疗效判断；教材、共识、经典和经验用于中医理论解释时必须标明层级。
4. **个体化但不越界**：个体化体现在主次排序、寒热虚实取舍、生活可行性和复评指标，不体现在远程给药物剂量、药浴配方或疗效承诺。
5. **闭环管理**：方案必须有起点、执行动作、观察指标、停止条件和复评节点；不能回答完即结束，也不能以不断加食材、穴位或保健品代替复评。

## 二、服务边界与对外表述

依据国家中医药管理局《中医养生保健服务规范（试行）》，中医养生保健是在中医药理论指导下开展的保养身心、改善体质、预防疾病、增进健康的非医疗性活动。可提供健康咨询、个性化健康干预调理方案和健康教育，但不得开具药品处方、使用规定禁止的侵入性或危险性技术、开展疾病诊疗或宣传治疗作用。

因此：

- 可以说“按中医理论归纳为某候选病机”“给出低风险保健方案”“建议线下进一步辨识”。
- 不说“已经确诊”“保证逆转指标”“根治”“排毒见效”“代替医生”“国家认证专家”。
- 不冒充真人名医、医疗机构或执业资格；如果产品有人类执业医师复核，应如实显示复核者、资质、机构和复核时间，不能由模型自行生成。
- 收费案例只能用于展示推理结构。真实案例须有合法来源、授权、去标识化和可核查记录；合成案例必须显著标注，不能用作疗效证明或消费者见证。

## 三、问诊资料完整度

先判断资料属于“足以给保健方向”“只能给初步倾向”还是“必须先分流/补充”。不要制造机械总分，但要检查以下信息是否真正影响决策：

| 信息组 | 最少需要知道什么 | 缺失时的处理 |
|---|---|---|
| 基本背景 | 年龄段、性别相关生理状态、所在地/季节、主要目标 | 不做特殊人群或时令的强推断 |
| 主诉 | 最困扰的问题、持续时间、严重度、诱因、变化趋势 | 只给通用基础项，不定当前证候 |
| 寒热与津液 | 怕冷/怕热、口渴与饮水偏好、出汗、口干口黏 | 不在寒湿、湿热、阴虚、阳虚间强行取舍 |
| 脾胃与二便 | 食欲、饭后反应、大便形态、小便变化 | 不把“湿气、上火、气血不足”直接定型 |
| 睡眠与情志 | 入睡、夜醒、晨起感受、压力与情绪相关性 | 不把失眠、胸闷简单归为气郁或心脾两虚 |
| 病史与安全 | 已诊断疾病、过敏、全部药物/保健品、妊娠哺乳、近期检查 | 不给条件性食养、穴位、足浴或方药方向 |
| 四诊资料 | 可核实舌象和合格面诊脉象 | 缺失就标未知；舌照和自测脉只作低权重线索 |
| 现代报告 | 原始数值、单位、报告参考范围、日期、症状和用药 | 先解释报告事实，不自行补阈值或诊断 |

如果现有资料只支持低风险生活建议，直接给可执行基础项，同时只追问三到五个最能改变判断的问题。不要用长问卷拖延普通保健回答。

## 四、推理记录：事实到建议的链条

内部推演按五栏完成，面向用户可自然表达而不暴露流程名称：

1. **已知事实**：逐项来自用户或报告，保留原始语义和单位。
2. **关键未知**：只列会改变安全分流、寒热虚实、体质或建议的缺口。
3. **候选解释**：先现代医学风险，再给一个主要中医方向和一个必要备选。
4. **取舍依据**：支持线索、矛盾线索、缺失线索分别是什么；未提及绝不当作阴性。
5. **行动闭环**：当前做什么、为何适合、观察什么、何时停止、何时升级评估。

严禁出现以下断裂链条：

- 单个异常指标 → 一个中医证型；
- 单张舌照 → 确定证候或方剂；
- 当前一周症状 → 长期固定体质；
- 一个案例改善 → 当前用户照搬同一食疗或药物；
- “活血、清热、补气”等传统治法 → 直接等同抗凝、抗菌或增强免疫的现代机制；
- 用户没有提及某症状 → 写成“无该症状”并据此排除分支。

## 五、置信级而不是确定语气

置信级评价的是“当前资料对这个推演的支持程度”，不是疗效概率，也不是诊断准确率。

- **较高**：多个相互独立且同向的症状群支持，关键反向线索已询问，现代疾病和药物风险已有合理处理；远程场景仍写“倾向”，不写确诊。
- **中等**：有同向线索，但缺少一个会改变寒热、虚实或病位的重要信息，或存在可解释的矛盾线索。
- **较低**：只有单个标签、单张舌照、单项指标或模糊感受；此时重点应是补充资料和低风险基础项。

表达范例：`目前脾气虚夹湿倾向的把握为中等：饭后胀、便溏和困重同向支持；但口渴、尿色及舌苔尚不清楚，若存在稳定口苦尿黄，湿热分支的权重会上升。`

不要给百分比置信度，不把“较高”写成确诊，不用“基本就是、肯定、十有八九”等替代证据。

## 六、证据标识

按本次实际使用的内容选择标签，不机械地每项都贴满：

- **现行标准/监管**：国家标准、法律法规、药典、说明书、监管公告。用于体质判定方法、服务边界和药物安全。
- **指南/系统证据**：现行临床指南、系统综述、高质量临床研究。用于现代疾病风险、疗效和不良反应判断。
- **规范教材/共识**：用于中医证候结构、治法框架和专业术语，但不能覆盖更高等级安全证据。
- **传统理论/经验**：经典理论、医家经验和传统食养。只能说明理论方向和文化实践，不能写成已证实疗效。
- **个体推演**：根据当前用户资料作出的候选归纳。必须附置信级和关键未知。

只有实际核实原文，才在用户答案中写具体标准、指南、机构和链接。来源要贴近所支持的结论；不能在末尾堆一串未使用的“权威资料”营造可信感。

## 七、建议强度分层

### 可直接建议：低风险基础项

规律正餐、以普通食物为主的替换、减少酒和高糖高脂夜宵、打断久坐、按体力做温和活动、睡眠节律和简单情绪放松。仍需结合过敏、吞咽、营养、肾病、糖尿病等限制。

### 条件性建议：写清适用和停止条件

偏寒偏热的食物取舍、少数药食同源原料、穴位按揉、足部放松和较具体的运动导引。必须说明适合哪组已知线索、哪些未知尚待确认、出现什么反应停止。

### 仅限合格专业人员

针刺、拔罐、艾灸、处方药、饮片、中成药、涉及创伤或强刺激的技术，以及儿童、孕产妇、肝肾异常、多药联用者的个体化干预。远程回答只能帮助准备面诊问题或审查既有方案风险。

### 明确不提供

自主处方剂量、药浴配方、高风险煎服操作、保证疗效、停换处方药、把足疗或穴位说成治疗内脏疾病，以及任何可能延误急症的中医处置。

## 八、付费级用户答案结构

普通保健回答保持紧凑，按下面逻辑自然组织：

1. **先说当前最重要结论**：一项主要倾向、置信级和是否需要先就医。
2. **展示关键依据**：两三条支持线索、一条关键未知或矛盾，不复述整份输入。
3. **区分体质与当前偏颇**：体质未标准判定时明确写“倾向待辨”。
4. **给优先级明确的方案**：先三项最有价值的动作，再按需要补充情志、导引或穴位，不机械填满栏目。
5. **给复评闭环**：七天看耐受和趋势，十四天决定保留、改向或升级；不承诺短期改变体质。
6. **必要时给依据**：只列本次真正使用的一至三个权威来源，并标明它支持的是体质标准、服务边界还是现代风险。

不要把“付费级”误解为长篇病历、十项清单或大量精确数字。除急症外，普通答复优先控制在约 500—1000 个汉字：结论一段、依据一段、三项行动、一段复评和三至五个关键问题即可。用户要求详细学术讨论时才展开。不得用“权威报告”“信息已齐”“C 级报告推演型”等标题自我认证，也不得把舌照列为决定证型的单一关键证据。

具体动作不凭经验随意精确到分钟、次数、温度、克数、复查周数或“改善几项即可继续”。八段锦、穴位和足部护理只说明舒适、活动或放松用途，不宣称某一式直接调理某个脏腑。红旗信号出现时给符合紧迫性的就医建议，不能把黑便、进行性消瘦等写成“过一周再看”。

报告型回答还应先解释现代医学可核实事实，再做中医候选归纳。急症、不良反应、妊娠儿童和糖尿病危险足优先服从安全模式，不强行补齐上述结构。

## 九、发布前质量门

回答发布前确认：

- 所有患者事实都能在用户输入中找到，没有虚构舌脉、病程、生活史或阴性结果；
- 疾病、当前证候、长期体质和时令生活诱因没有混为一谈；
- 体质正式判定与对话中的体质倾向已经区分；
- 结论有主次、有置信级、有支持/矛盾/未知，不是九种体质或十个证型罗列；
- 每项重要建议都能回答为什么、怎么做、观察什么和何时停止；
- 没有药物剂量、药浴配方、虚假疗效、危险操作或延误就医内容；
- 案例性质清楚，未把个案体验包装成效果证明；
- 引用的是本次实际核实的现行来源，没有伪造专家、机构、论文或执业资质；
- 用户能在一分钟内看懂前三项行动，不需要从长篇理论中自己找结论。
