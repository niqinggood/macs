# 证据与来源

## 1. 来源优先级

按具体问题选择最高等级且可访问的来源：

1. 使用地现行法律法规、药典、药品说明书、监管警示、国家/专业学会临床指南；
2. 系统综述、循证指南、注册临床试验和高质量随机对照研究；
3. 规范教材、行业标准和多学科专家共识；
4. 经典医籍与有清楚传承来源的理论阐释；
5. 个案、名家经验和民间经验。

低层级来源可以解释传统用法或生成待验证假设，不能覆盖高层级的安全警示，也不能仅凭历史悠久推出有效。

## 2. 必须查询最新资料的情形

- 饮片或中成药的剂量、炮制、煎服、禁忌、说明书适应证和批准状态；
- 中西药相互作用、药物不良反应、肝肾毒性和召回/监管警示；
- 妊娠、哺乳、儿童、老年、肝肾功能异常或手术期使用；
- 某疾病的当前诊疗指南、针灸/中药疗效比较或最新系统综述；
- 执业资质、医保、法律、保护物种与跨地区产品监管。

检索时优先官方和原始研究，记录来源机构、标题、发布日期/版本、适用地区与访问链接。若资料相互冲突，说明冲突来自版本、制剂、研究人群或监管辖区，不自行拼成确定结论。

只有在当前回答中实际核实到原文，才可写“某指南/通报明确”“研究证明”或给精确阈值、间隔和相互作用强度。未核实时改写为“需要接诊医生/药师结合当前说明书核实”，不能列一个可能存在的文献标题后再声明自己没有读原文。面向用户的回答不得引用 skill 内部文件、运行时目录或工具输出路径。

## 3. 表述证据

- **经典理论**：写 `按某经典/学派的理论框架……`，不用 `研究证明`。
- **经验/共识**：写清来源和适用人群，不把专家意见写成高确定性疗效。
- **临床研究**：说明研究对象、干预形式、对照、主要结局、局限和是否能外推到当前用户。
- **安全信号**：即使因果尚不完全确定，也按严重程度采取谨慎行动；不建议再挑战试验。
- **证据不足**：直接说哪一环不足，以及下一步哪类检查或研究能提高确定性。

中医病机解释与现代生物医学机制是不同层级的陈述。除非有直接研究，不把 `活血化瘀` 翻译成抗凝，不把 `清热解毒` 翻译成抗菌/抗病毒，也不把 `补气` 翻译成增强免疫。
