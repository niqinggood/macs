# 中医基础辨证词典

本文件提供组合推理语言，不是“症状—证型”查表。证候至少由病程、主症、寒热、饮食二便、睡眠情志及可信舌脉中的多项相互支持；单个词不能定证。

## 八纲

- **表/里**：表多见病程短、恶寒发热、头身痛等外感线索；里指脏腑气血津液层面。慢性病不自动等于里虚，急性病也可迅速入里。
- **寒/热**：寒要看畏寒喜暖、口不渴或喜热饮、分泌物清稀等组合；热看发热烦热、口渴喜冷、分泌物黄稠等。局部灼热或一次怕冷不能单独定性。
- **虚/实**：虚是正气、功能或物质不足；实是邪气、积滞、痰湿、瘀血等偏盛。久病可虚实夹杂，不能见疲劳就判虚。
- **阴/阳**：是总纲。阴虚常偏津血不足与虚热，阳虚常偏温煦推动不足；必须与具体脏腑和病机结合。

## 气血津液

| 证素 | 常见支持组合 | 关键鉴别 |
|---|---|---|
| 气虚 | 乏力、少气懒言、活动后加重、自汗、功能低下 | 先排贫血、甲状腺、心肺、睡眠和药物因素 |
| 气陷 | 气虚基础上久泻、下坠或脏器下垂感 | 结构性疾病和盆底问题须现代评估 |
| 气滞 | 胀闷走窜、与情绪相关、嗳气或叹息后缓解 | 持续固定痛、体重下降和器质性病变不是“肝郁”可概括 |
| 血虚 | 面色淡、心悸、头晕、肢麻、月经量少等组合 | 必须核对血常规、铁/B12/叶酸和失血来源 |
| 血瘀 | 固定刺痛、夜间加重、瘀斑、经血块等组合 | 不等于高凝或血栓；急性胸痛、偏瘫等先急救 |
| 阴虚 | 口咽干、潮热盗汗、五心烦热、舌偏红少津 | 脱水、感染、药物和内分泌问题先核实 |
| 阳虚 | 畏寒、四肢冷、清稀、夜尿或水肿、舌淡胖等组合 | 甲减、贫血、心肾疾病和循环问题要排查 |
| 津亏 | 口干、皮肤干、便干、尿少、舌少津 | 不能默认“多喝水”，心肾限液者先问医嘱 |
| 痰湿 | 困重、胸脘痞满、痰多、苔腻及代谢聚类 | 肥胖或血脂异常单项不能直接定痰湿 |
| 湿热 | 困重黏滞兼口苦、身热不扬、分泌物黄稠、苔黄腻 | 感染、胆道和泌尿问题先现代分流 |

## 常见脏腑证候主线

- **心**：心气/阳不足偏心悸气短、活动后加重；心血/阴不足偏心悸失眠、健忘或虚热。胸痛、晕厥和持续心律异常先做心血管评估。
- **肺**：肺气虚偏久咳气短、自汗；肺阴虚偏干咳少痰、咽干；痰湿/痰热偏痰多黏腻或黄稠。低氧、咯血、呼吸困难先就医。
- **脾胃**：脾气虚偏食少、便溏、乏力；脾阳虚兼明显寒象；胃阴不足偏胃脘隐灼、口干、饥不欲食；食积偏近期饮食诱发、脘腹胀满、嗳腐。
- **肝胆**：肝气郁结偏情绪相关胀痛；肝火偏急躁、口苦、目赤等热象；肝阳上亢常有下虚上亢背景；肝血/阴不足偏目涩、筋脉失养。不能由转氨酶异常直接判“肝郁”。
- **肾**：肾阴虚与肾阳虚均需一组全身线索；腰酸、耳鸣或性功能问题单项不能定“肾虚”。现代肾功能异常也不等同中医肾虚。
- **膀胱、大肠、小肠**：尿频尿痛、血尿、急性腹泻、便血和肠梗阻线索先按现代疾病分流，再讨论湿热、寒湿或虚实夹杂。

## 病因与病机连接

- 六淫是传统病因分类，必须结合季节、暴露和症候，不能用“受寒”解释所有感染或疼痛。
- 饮食不节可形成食积、湿浊或脾胃受损，但要区分总能量、酒精、营养不足、食物不耐受和真实疾病。
- 七情可影响气机、睡眠和症状感受，不得把器质性病变归咎于“想太多”。
- 劳倦、久坐、睡眠不足可作为诱因；治疗仍要处理基础病、工作负荷和行为环境。

## 舌象使用

先看照片条件：自然光、无滤镜、伸舌不过久、近期无有色食物/漱口水。记录舌质、舌形、苔色、苔厚薄润燥与分布，不只看裂纹或齿痕。

- 舌淡可支持气血或阳气不足，也可受光线影响；舌红需结合热象和津液。
- 苔腻可支持湿浊、痰湿或食积，厚黄腻需结合热象；刚进食后的舌苔不可靠。
- 剥苔、少苔可提示胃阴/津液不足等候选，也可能与局部舌病有关。
- 紫暗、瘀点只能作血瘀线索，不诊断血栓或循环障碍。

## 脉象使用

脉诊受体位、运动、咖啡因、药物、发热、心律和操作者影响。只有合格临床人员记录时才作为较高可信证据。浮沉、迟数、虚实、滑涩、弦细等必须与症状和舌象互证；用户用设备心率或自行摸脉不能直接翻译为传统脉象。
