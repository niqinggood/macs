# 食疗基础知识

食疗是普通膳食的辅助设计，不是缩小版中药处方。先满足能量、蛋白质、纤维、液体和疾病饮食要求，再谈性味归经。国家卫健委慢性病食养指南入口：<https://www.nhc.gov.cn/wjw/c100378/202402/afd5dda4bd6745fda10aad8d43a16369.shtml>。

## 使用规则

1. 先查过敏、妊娠哺乳、儿童/高龄、吞咽、糖尿病、肾病限钾限磷、痛风、肝病、抗凝/抗血小板药和总能量。
2. 优先普通食材和正常餐食，不默认药材泡水、粉剂、膏方或长期单一食谱。
3. 一次给一到三项最匹配选择，写清替换什么、频率范围和观察点；不把食物说成降糖、降压、抗癌或治失眠。
4. 寒热未分时先给平和方案，不同时给大量寒凉清热和辛温补益。

## 常用食材与边界

| 食材 | 传统食养方向 | 更适合的表现 | 主要限制 |
|---|---|---|---|
| 山药 | 健脾益气、兼顾肺肾 | 食少、便溏、乏力 | 计入主食/碳水；便秘者注意总纤维和水分 |
| 莲子 | 健脾、固涩、养心 | 便溏、心悸睡不稳 | 便秘、腹胀明显者不大量食用 |
| 白扁豆 | 健脾化湿 | 食少便溏、暑湿困重 | 必须熟透；豆类过敏、胀气者慎 |
| 薏苡仁 | 渗湿健脾的传统用途 | 困重、便黏、苔腻方向 | 妊娠期不自行长期大量用；计入谷物，肾病需个体化 |
| 赤小豆 | 利湿的传统用途 | 轻度困重、水湿方向 | 不能替代利尿治疗；肾病钾限制需核对 |
| 绿豆 | 清暑的传统用途 | 暑热口渴、偏热体质 | 脾胃虚寒、腹泻者少用；含碳水 |
| 冬瓜 | 清淡、利水的食养选择 | 肥甘后困重、偏热湿 | 不声称消肿治疗；限液/肾病按医嘱 |
| 萝卜 | 消食下气的传统用途 | 食积胀满、嗳气 | 胃肠敏感者按耐受；不与“补气药相克”作绝对结论 |
| 生姜 | 温中散寒、和胃 | 畏寒、胃部冷感、恶心方向 | 口干口苦、灼热反酸、出血风险者不大量浓用 |
| 梨 | 润燥生津 | 干咳、咽干、便干方向 | 糖尿病计入水果量；腹泻和寒凉不耐者控制 |
| 百合 | 润肺、宁心的传统用途 | 干咳、心烦睡不稳 | 不能替代失眠/肺病治疗；过敏者避用 |
| 大枣 | 补中、调和的传统用途 | 食少乏力方向 | 糖分较高；肥胖、糖尿病和龋齿人群控制数量 |
| 枸杞 | 滋补肝肾的传统用途 | 眼干、腰膝酸软待辨 | 与华法林等药物存在潜在相互作用顾虑，正在用药者先核对；控制糖分 |
| 黑芝麻 | 润燥、补益的传统用途 | 便干、精血不足待辨 | 能量高；腹泻者不宜大量 |
| 核桃 | 温补、润肠的传统用途 | 畏寒、腰膝酸、便干方向 | 坚果过敏、能量控制、吞咽风险 |
| 山楂 | 消食化积的传统用途 | 肉食油腻后胀满 | 胃酸/溃疡不适、妊娠和抗凝用药者不自行大量浓用 |
| 陈皮 | 理气和中、燥湿化痰 | 胀满、嗳气、痰湿方向 | 阴虚燥咳、口干明显者不长期浓饮；药用品质和农残需注意 |
| 玫瑰花 | 疏肝理气的传统用途 | 情绪相关胸闷、经前胀 | 妊娠、过敏、出血倾向者先核对；不替代心理治疗 |
| 菊花 | 疏风清热、清头目 | 目涩、头胀、偏热方向 | 低血压、腹泻、寒凉不耐或过敏者控制 |

## 按证候组合普通餐食

- **痰湿/湿浊**：以全谷杂豆、蔬菜、菌菇和足量蛋白替换甜饮、油炸和夜宵；可用冬瓜、白扁豆或少量薏苡仁作食物变化，不做“祛湿水”单一疗法。
- **湿热/胃热**：减少酒、烧烤、辛辣和高糖高脂；选择清淡熟食和正常饮水，不要求长期冷饮、生食或苦寒代茶饮。
- **脾气虚**：规律进餐、熟软易耐受、足量蛋白；山药、莲子、白扁豆可作为主食/配菜的一部分，避免只喝粥造成蛋白不足。
- **气血不足**：优先查贫血病因；食物重在足量蛋白、铁、叶酸和维生素 B12 来源，红枣红糖不能替代补铁和止血治疗。
- **阴虚津亏**：无心肾限水时正常饮水，搭配梨、百合、芝麻等普通食物；避免用高糖甜汤“滋阴”。
- **阳虚/寒凝**：以温热熟食、规律活动为主，可少量生姜调味；不能据怕冷就大量羊肉、附子或药酒。
- **气郁**：规律进餐、运动和情绪性进食记录优先；玫瑰、陈皮只作少量风味，不承担治疗。
- **血瘀兼夹**：戒烟、活动和规范心血管管理优先；抗凝/抗血小板用药者不自行叠加山楂、药酒或活血药材。

## 停止条件

出现皮疹、口唇肿胀、喘憋、持续腹泻呕吐、明显头晕、低血糖、出血或原症状加重时停止新增食疗并按严重程度就医。所谓排湿、排毒或好转反应不能解释不良反应。
