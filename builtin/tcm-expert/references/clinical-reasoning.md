# 辨证与临床推理

## 1. 先区分五个概念

- **中医病名**：对当前临床问题的疾病范畴描述，如咳嗽、胃脘痛、眩晕。不能仅凭名称推出证候。
- **证候**：特定阶段病因、病位、病性和邪正关系的综合状态，会随病程和治疗变化。
- **病机**：把事实连接到证候与治法的因果解释链；不能只写一个证名。
- **体质**：相对稳定的倾向，不等于当前疾病证候，也不能单独决定治疗。
- **西医诊断**：独立的临床分类。可与中医病名并列，但不互相证明。

## 2. 建立可审计的病例摘要

先在内部整理以下字段，未提供即标记未知：

| 字段 | 要点 |
|---|---|
| 主诉与目标 | 最困扰的问题、用户希望改善什么 |
| 时间轴 | 起病、诱因、进展、周期性、既往发作和治疗反应 |
| 主症 | 部位、性质、程度、频率、加重与缓解因素 |
| 全身线索 | 寒热、汗、口渴、食欲、胸腹感受、二便、睡眠、精力、情志 |
| 专科线索 | 呼吸、心血管、妇科、皮肤、疼痛等与主诉相关内容 |
| 舌脉 | 观察者、时间、光线/饮食染苔、是否由合格临床人员记录 |
| 现代医学事实 | 已确诊疾病、检查结果、生命体征、治疗计划 |
| 安全背景 | 年龄段、妊娠哺乳、过敏、肝肾病、出血风险、全部用药与补充剂 |

事实、推断和未知必须分开。旧资料与当前症状冲突时，以时间标记，不强行合并成一个静态证型。

## 3. 选择辨证体系

所有病例都可先用八纲确定大方向，再按问题选择一到两个最有解释力的体系：

- **脏腑辨证**：慢性内科、功能性和多系统症状常用。
- **气血津液辨证**：疼痛、出血、水湿痰饮、津亏、气机异常等。
- **病因辨证**：外感六淫、疫疠、七情、饮食劳倦、外伤等确有病程支持时使用。
- **六经辨证**：外感病或病程传变与六经层次真正吻合时使用。
- **卫气营血/三焦辨证**：温热病的阶段、热势和营血表现支持时使用。
- **经络辨证**：疼痛、麻木或运动障碍沿经络分布且需要解释选穴时使用。

不要为了“完整”把每个体系都套一遍。若体系之间得出不同结论，写明各自依据和能区分它们的下一条信息。

## 4. 形成病机链

依次回答：

1. **病因/诱因**：哪些是已知事实，哪些只是可能因素？
2. **病位**：表里、脏腑、经络、上中下焦；证据是什么？
3. **病性**：寒热、虚实、燥湿、升降出入是否异常？
4. **病理产物**：痰、湿、瘀、食积等是主因、结果还是兼夹？
5. **邪正与先后**：本虚标实、因实致虚或虚实夹杂的先后关系是否被病程支持？
6. **主证与兼证**：哪个解释覆盖最多关键事实且矛盾最少？兼证是否真的改变治法？

把答案压缩成一条可检验的链，例如：`长期劳倦与饮食失节（事实）→ 脾运受影响（推断）→ 食后腹胀、便溏、乏力相互支持（事实）→ 脾气虚倾向（B级）`。若舌脉、寒热或病程不支持，就明确列为矛盾或未知。

时间段、经络当令和五行类比只能作为传统理论讨论，不能成为个体辨证证据。不得从“上午乏力、凌晨易醒、某时段疼痛”直接推出脾虚、肝病或某经异常；先核对睡眠、进食、用药、工作节律和稳定症状群。

## 5. 主证与鉴别

- B 级及以上通常只保留一个主导 `证候倾向` 和一个会改变治法的备选。
- C 级只写辨证轴，例如 `先辨寒热与虚实，再结合食欲二便判断病位是否偏脾胃`，不要列出一长串证名。
- 每个候选都写：支持事实、反对/矛盾事实、关键缺失信息、若成立会怎样改变治则。
- 单个常见症状不能锁定证候：怕冷不等于阳虚，口干不等于阴虚，苔腻不等于痰湿，刺痛不等于血瘀。
- 压力大、思绪多或叹气不等于肝郁；必须存在与情绪同步的胀闷、走窜、嗳气/叹息后缓解等气机证据。否则只写“情志相关，肝郁待辨”。
- 舌脉与症状冲突时不机械地让舌脉“裁决”；先检查观察条件、药食染苔、急慢性阶段和记录可信度。

## 6. 从理到法

治法必须逐层对应：

`核心病机 → 治则 → 治法 → 可讨论的方/药/穴位方向 → 复评指标`

例如，只有在核心病机支持时才讨论补益、清热、温阳、活血、攻下等方向。不得用症状相似或流行方剂替代辨证。治疗目标应可观察，如症状频率、睡眠、食欲、二便、活动耐量、客观复查和不良反应，而不是只写“调理体质”。

## 7. 随访与动态辨证

给出与风险相称的复评计划：

- 哪些主症应在何种时间尺度内改善；
- 哪些舌脉或兼症变化提示病机转变；
- 哪些现代医学指标需要复查；
- 哪些新症状提示停下自行尝试并尽快就医；
- 若无效，是证候判断、执行依从性、药品质量、剂量/剂型，还是原诊断需要重新评估。

不能把短暂波动一概解释成“瞑眩”或“排病”。不良反应和病情恶化必须先按安全问题处理。普通保健不凭经验给精确复评周期；主 Skill 约定的七天耐受、十四天去留是服务复盘框架，不是疗效承诺。
