# 中医保健专家能力核心

本文件用于付费级、权威、专业、复杂症状或健康报告咨询。目标是让回答像一次有边界的专业评估：问题定义准确、证据分级清楚、鉴别真正改变决策、行动与病机相连。它不是处方教材。

## 一、先确定咨询模式

| 模式 | 适用 | 专业目标 | 不做什么 |
|---|---|---|---|
| 风险分流 | 急症、明显不良反应、特殊人群、危险足 | 明确紧迫性和下一步 | 不展开辨证和养生清单 |
| 症状辨析 | 消化、睡眠、疲劳、疼痛、月经等 | 一主一备、关键未知、低风险行动 | 不把模糊症状写成确定证候 |
| 体质辨识 | 长期稳定倾向 | 区分标准判定与倾向 | 不用当前短期症状代替量表 |
| 报告归纳 | 化验、影像、穿戴设备 | 先解释报告事实，再给低置信候选病机 | 不补诊断阈值、严重程度和检查套餐 |
| 既有方案审查 | 用户已有食疗、方药、足疗或穴位方案 | 找最高风险、适用前提和需专业复核项 | 不重开处方或提供剂量替换 |
| 案例与证据 | 朋友、网友、名医案例、研究 | 判断证据能否外推 | 不把改善故事变成照方依据 |

## 二、最小病例数据集

只问会改变安全、寒热、虚实、病位或行动的内容。优先级从上到下：

1. **主诉与时间轴**：最困扰的一个问题；多久；突然还是渐进；稳定、波动还是加重；明确诱因和缓解因素。
2. **危险信号**：意识呼吸、胸痛晕厥、出血、持续剧痛、黄疸、明显非意愿体重变化、进行性神经症状。
3. **现代医学背景**：已诊断疾病、近期原始报告、药物与补充剂、妊娠哺乳、过敏和既往治疗反应。
4. **寒热津液**：畏寒或烦热、饮水偏好、口干口黏、汗出和分泌物清稀黄稠。
5. **脾胃二便**：食欲、食后反应、腹胀痛、便形频率与排便感、小便变化。
6. **睡眠情志与活动**：入睡/夜醒/早醒、日间功能、压力和症状是否同步、咖啡酒精、久坐和活动耐受。
7. **可信四诊**：舌照条件与时间；脉象记录者是否合格。舌脉只修正已有推演，不凭一项创造证候。

信息缺失不是要求一次问满。已有资料足以给低风险基础项时，先帮助用户，再问三至五个最能改变分支的问题。

## 三、内部证据分级

- **强支持**：两个以上相互独立、稳定、同向的症状群，且病程和诱因一致；或可靠检查与症状共同支持同一现代风险。
- **有限支持**：只有一个症状群，或虽有多项信息但存在关键矛盾/缺失。
- **线索级**：单一症状、舌照、时段、设备风险分、单项指标、网络测试或他人体验。
- **不可用于个体结论**：教材典型描述、经典理论、食物属性、病例故事和模型记忆中的统计数字。

面向用户只写较高/中等/较低把握，不暴露内部标签。较低把握时使用辨证轴，不列串联证名。

## 四、病机链审查

每个主方向至少回答：

1. 病位为什么在这里，而不是因为证名习惯？
2. 寒热和虚实分别由什么事实支持？
3. 痰、湿、瘀、食积等是用户事实、推断还是仅候选？
4. 哪条已知事实与主方向不一致？
5. 哪个备选会让饮食、起居或专业转诊方向发生实质变化？

若无法回答其中三项，不输出具体证候名；改写为下一步辨别方向。

## 五、常见误判校正

| 输入 | 不能直接得出 | 还需要什么 |
|---|---|---|
| 上午乏力、凌晨醒 | 某经当令、某脏虚 | 总睡眠、活动、药物、进食、稳定症状群 |
| 压力大、想得多 | 肝郁、肝火 | 情绪相关胀闷走窜、叹息缓解及热象 |
| 口干 | 阴虚 | 饮水、环境、药物、尿量、潮热盗汗和舌津 |
| 手脚冷 | 阳虚 | 全身畏寒、清稀、水肿/夜尿、活动耐受及现代排查 |
| 苔厚腻 | 痰湿或湿热 | 照片条件、寒热、食欲、二便、口黏口苦 |
| 血糖血脂或脂肪肝 | 痰湿证、痰湿质 | 困重、胸脘痞满、痰多、二便和标准体质问卷 |
| ALT 升高 | 肝火、肝郁、湿热 | 先做现代病因和风险评估；中医分支仍靠症状组合 |
| 经血有块 | 血瘀 | 疼痛性质、块下痛减、颜色、经量、寒热和妇科背景 |
| 朋友吃了有效 | 当前用户适用 | 不能由案例完成；回到当前用户资料 |

## 六、专病问题表示

### 消化与便溏

先写 `食后症状 + 便形 + 病程 + 寒热 + 体重/红旗`。脾气虚夹湿需要食后胀/食少、便溏或黏、乏力困重等组合；偏寒只是一条修饰线索。没有明显全身寒象，不上升为脾阳虚。

### 睡眠不稳

先写 `睡眠类型 + 日间损害 + 诱因 + 呼吸/肢体/物质线索 + 情绪安全`。压力相关只说明诱因；肝郁、痰热、心脾两虚、阴虚等必须各自有改变治则的组合。睡眠卫生建议不随意给钟点和分钟。

### 疲劳怕冷

先写 `疲劳与活动关系 + 睡眠恢复 + 寒冷范围 + 饮食二便 + 现代排查`。先排贫血、甲状腺、营养、感染、心肺肝肾、药物和情绪；中医只能在同向组合上归纳。

### 代谢与肝脏报告

先逐项描述相对报告参考范围是否异常，不自行分轻中重。第二步说明需要正规医学评估，不列套餐。第三步才问困重、胸脘、食欲、口黏口苦、二便、寒热等中医线索；报告本身只决定现代风险，不决定证候。

### 月经与疼痛

先写 `周期/经量 + 疼痛时序性质 + 出血/妊娠/感染安全 + 寒热全身线索`。气滞血瘀、寒凝、湿热和气血不足必须有各自组合，不能见血块或怕冷就定证。

## 七、建议的专业匹配

- 主方向和备选都适用：可直接建议普通正餐、减少酒和高糖高脂夜宵、打断久坐、温和活动、睡眠节律和压力管理。
- 两个分支下方向相反：先不推荐偏寒偏热食材、药食同源原料、足浴、艾灸或强刺激穴位，优先追问。
- 用户有慢病、孕产、儿童、肝肾异常、多药联用或足部风险：普通支持和转诊优先，不用“条件式偏方”绕过限制。
- 每项行动写类别和选择原则，不给固定分钟、次数、克数、疗程或复查周期；用户已有医嘱或本轮核实指南时才准确复述。

## 八、付费级发布标准

一份合格回答应让用户快速看清：当前最重要问题、把握多大、为什么、现在只做哪三件事、什么情况停止、还缺哪几个关键事实。删掉以下内容：

- 输入复述、教材式证候清单和经络时辰套话；
- 与本题无关的食物、穴位、功法或检查套餐；
- 未经本轮核实的机构、指南、论文和链接；
- “典型、基本就是、材料已齐、权威解读”等自我认证；
- 任何为了显得可执行而编出的分钟、次数、温度、克数和周期。

专业不是篇幅长，而是分流正确、证据与结论匹配、鉴别会改变决策、建议能闭环、边界可信。
