# Content Creation & Thinking Skills

Two domains: content production (external output) and thinking frameworks (internal clarity).

---

## ⚠️ IRON RULES

1. **Python only** via `write_file` + `code_check run`. NEVER curl/cli.
2. **Original over aggregated**: Add analysis and perspective, don't just list headlines.
3. **Platform-aware formatting**: Each platform has different tone, length, and structure requirements.
4. **No fabricated content**: Don't invent facts, trends, quotes, or statistics.
5. **Output to `.openkitty/storage/`**: All drafts and reports go here.

---

## Part A: Content Production

| Sub-Skill | Use For | Example |
|-----------|---------|---------|
| **daily-trending** | Hot topics across platforms (Weibo, Zhihu, Bilibili, HackerNews) | "今天有什么热点" |
| **social-media-publish** | Platform-optimized drafts (小红书, 知乎, 微博, LinkedIn) | "帮我在小红书发文" |
| **tech-news-daily** | Daily tech news roundup | "今天的科技新闻" |
| **work-report** | Structured reports (周报/月报/季报) | "帮我写周报" |
| **moltbook** | AI Agent social network trending digest | "Moltbook热点" |

### Quality Standards

| ✅ Good | ❌ Bad |
|---------|--------|
| Platform-appropriate tone and length | One-size-fits-all text |
| Catchy title + structured body | Headline-only dump |
| Specific examples and data | Vague generalizations |
| Original angle or insight | Copy-paste aggregation |

## Part B: Thinking Frameworks

| Sub-Skill | Use For | Example |
|-----------|---------|---------|
| **brainstorming** | Generate ideas, explore possibilities | "帮我想想有哪些方案" |
| **critical-thinking** | Evaluate ideas for flaws and blind spots | "帮我审视这个方案" |
| **plan-mode** | Structured implementation plans | "帮我做个实施计划" |
| **productivity** | Workflow optimization, time management | "怎么提高效率" |
| **self-evolution-weekly** | Weekly retrospectives | "帮我做本周复盘" |
| **summarize** | Extract key points from long content | "总结一下这篇文章" |

### Quality Standards

| ✅ Good | ❌ Bad |
|---------|--------|
| Actionable and specific | Abstract philosophy |
| Considers trade-offs | One-sided analysis |
| Structured output with clear sections | Stream of consciousness |
| Concrete next steps | "Think about it more" |

---

## Anti-Patterns

| # | Anti-Pattern | Correct Behavior |
|---|-------------|-----------------|
| 1 | Posting empty headlines without analysis | Every post needs original commentary |
| 2 | Using wrong platform format (e.g., LinkedIn tone on 小红书) | Check platform conventions first |
| 3 | Summaries that just restate the original | Extract key insights and decisions |
| 4 | Plans without verification steps | Every plan step needs a way to check it worked |
