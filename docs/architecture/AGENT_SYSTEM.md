# OpenKitty — AI 数字员工平台

## 产品定位

OpenKitty 是一个**企业级 AI 数字员工平台**，让每家公司都能拥有自己的 AI 团队。不是聊天机器人，不是 Copilot 插件——而是能独立完成工作任务的 AI 员工：分析财报、审查合同、撰写标书、采集客户、运营社交媒体、填报 CRM，7×24 小时在线。

**一句话**: 给中小企业一个用得起的 AI 团队。

OpenKitty 是独立自主研发的 AI Agent 系统，设计理念上全面超越 OpenClaw——不仅在个人应用场景下实现了更完整的多 Agent 协作能力，更在企业级商业化需求上做了深度扩展：审批工作流、审计合规、数字员工体系、商业 Tier 分级、多渠道接入、自动更新闭环。WorkBuddy 提供了团队协作场景下的 Expert Teams 模式，但受限于 Slack 生态且缺乏 Pipeline 审批流。OpenKitty 从设计之初就以**企业全场景**为目标，独立实现多 Agent 协同、审批工作流、自动更新等完整闭环。

### 🔀 智能工作流

不是简单的 Prompt 链，是**企业级审批工作流**：

- 每步有工具白名单（能用的工具精确控制）
- 关键节点人工审批（HITL），超时自动升级
- 每步工具调用留痕：时间戳、参数、结果、耗时
- 条件分支、循环重试、并行步骤
- 46 个内置模板：采购审批/预算审批/合同审查/安全审计/发布检查/数据删除合规等

**意义**: 企业场景不只是"AI 能不能做"，更重要的是"谁批准的、什么时候批的、每一步做了什么"——合规留痕。

### 🤝 多 Agent 协同

不是单打独斗，是团队协作：
- 8 个预设专家团队模板（研究/编码/全栈/内容/PPT/审计/合同/竞对）
- 群组讨论 / 顺序执行 / 并行 / 投票决策
- 子 Agent 委派（一个 Agent 可以把子任务分给其他 Agent）

### 🧠 企业知识库

- 上传文档自动切片、向量化
- 全文搜索 + 语义搜索双路召回
- HyDE（假设文档增强）+ LLM Reranker 重排序
- 多租户隔离（不同部门/客户数据完全隔离）

### ⚡ 成本控制

DeepSeek KV 缓存优化：
- 自动前缀命中，Token 节省 80%+
- 实时监控面板：命中率、Token 消耗、延迟
- 并发控制：串行模式最大化缓存命中，并行模式最大化吞吐

### 🔄 自动更新

- 编译时版本号嵌入二进制
- 后台静默轮询服务器发现新版本
- Web UI 一键下载更新 + 实时进度条
- Windows/macOS 自动替换重启，无需手动操作

## 典型应用场景

### 🏢 私有化部署 — 数据不出企业

金融、医疗、政务等行业对数据合规有严格要求，公网 SaaS 方案无法通过安全审计。

**OpenKitty 方案**: 单二进制文件，拷到内网服务器直接运行。所有数据（对话记录、知识库文档、客户信息）存储在本地 SQLite，模型 API 调用通过企业防火墙直连，**全程数据不出企业内网**。

```
内网服务器 → ./openkitty → 本地 SQLite（对话/知识库/客户数据）
                ↓
          DeepSeek API（仅传输当前推理请求，不存储）
```

### 🖥️ IT 运维 — 7×24 自动巡检

运维团队每天要检查服务器状态、扫描日志异常、处理故障告警，重复劳动占用大量时间。

**OpenKitty 方案**: `@IT运维 检查所有服务器状态` → 自动执行 CPU/内存/磁盘/网络检查 → 分析系统日志提取异常模式 → 生成巡检报告 + 故障建议。配合 Cron 定时，实现无人值守自动巡检。

```
@IT运维 → 状态监控(persistent_shell) → 日志分析(Python) → 故障排查建议 → 巡检报告
```

### 📞 客服场景 — 工单自动闭环

客服团队面对大量重复问题，人工回复效率低、标准不统一。

**OpenKitty 方案**: `@客服专员 用户反馈App闪退怎么办` → 自动分类问题类型 → RAG 检索知识库匹配解决方案 → 生成标准话术回复。复杂问题自动升级人工，并附带 AI 初步分析结果。

```
@客服专员 → 问题分类(rag_search) → 方案匹配 → 标准回复 / 升级人工
```

### 📚 RAG 知识库 — 企业文档秒级问答

产品手册、技术文档、规章制度散落各处，员工查找耗时。接入 RAG 后秒级检索精准回答。

**OpenKitty 方案**: 上传文档 → 自动切片嵌入 → FTS5 全文搜索 + 向量语义搜索双路召回 → HyDE 假设文档增强 → LLM Reranker 重排序。多租户隔离，不同部门知识库互不可见。

```
上传产品手册 → 自动切片向量化 → @客服专员 这款产品保修多久？
                                       ↓
                              rag_search → 精准检索 → 引用原文回答
```
