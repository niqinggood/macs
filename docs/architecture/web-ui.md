# macs 原生 Web 与帮助文档

主工作台入口为 `/web/`，使用原生 HTML、CSS 和 JavaScript。资源由根目录 `assets.go` 嵌入，修改后重新构建 `./cmd/openkitty` 才能更新运行程序。

## 界面约定

主页面延续现有灰白背景、枣红色 macs 品牌、气泡消息与问题云。样式由 `web/style.css`、各功能样式和 `web/theme.js` 管理；字号继续响应 `--macs-font-scale`。帮助改动不覆盖主页面、侧栏、输入框或消息气泡的全局样式。

侧栏使用“新对话”“对话”“搜索对话”等名称。列表标题使用可读名称；名称包含原始会话 ID 时改用首个用户问题，没有名称和问题时显示“新对话”。搜索结果使用相同规则。ID 继续用于请求、恢复和复制，不作为列表标题。已知消息数为零的对话从历史列表隐藏，首次产生消息后再显示；数据保留。已有消息的对话保留计数，未提供计数的兼容结果仍可显示。

## 帮助与企业接入

`#helpModal` 使用独立目录栏和可滚动正文。`web/help_layout.css` 仅增强帮助内部的边线：概念说明、模式对比、企业调用链、步骤、表格与代码均有明确分隔。它使用既有 `--mac-modal-*` 变量，保持原有主题和字号偏好。

`web/agentos_help.js` 负责目录跳转、本机检查与 Python 源码加载。`web/help_layout.js` 增强代码语言栏、复制与步骤选中状态。复制不可用时选中代码并提示键盘复制。

公开接入指南面向通用企业业务后端，使用本机或 `.example` 占位地址，不包含具体平台的后台配置、实现文件、账号接口映射或专属检查脚本。长期接入契约以 `docs/agent-os-api.md`、`docs/openapi-agentos.yaml` 和 `docs/agentos-quickstart.md` 为准。

帮助导出使用独立的 `web/help_export.css`，保留说明区、步骤与代码的边线，展开折叠内容并移除交互控件。

## 验证

修改脚本后执行 `node --check` 并构建主程序。浏览器检查原有配色、问题云与消息气泡，以及零消息对话、已有消息对话、搜索和会话切换。中英文列表不展示原始 ID，零消息计数不显示，其他会话功能正常。

帮助检查桌面与手机、目录与步骤跳转、代码复制、源码加载、亮暗主题及导出结构。代码块可单独横向滚动，正文和窗口不得横向溢出。
