# Quant trader backend shims

These scripts expose the three upstream research runtimes through
`openkitty.professional-agent/backend/v1` NDJSON. They use only the Python
standard library themselves; every script must run with the separately
installed upstream project's Python interpreter.

All requests must declare `research` or `paper` mode and the exact safety
contract generated by `adapters.build_backend_request`. Structured live/order
flags are rejected. The shims contain no broker client and never submit an
order. Upstream stdout is suppressed so it cannot corrupt the JSON response;
one response is written for every non-empty stdin line.

## Entrypoints

- `tradingagents_backend.py` imports `TradingAgentsGraph` and calls
  `propagate(symbol, as_of)`.
- `ai_hedge_fund_backend.py` imports `src.main.run_hedge_fund` and supplies an
  in-memory blank paper portfolio.
- `fingpt_backend.py` calls one reviewed integration selected with
  `QUANT_TRADER_FINGPT_CALLABLE=module:function`, because FinGPT has no single
  stable runtime API. The callable receives the validated backend request as
  one mapping and may be synchronous or asynchronous.

Set each `*_REPO` to its checked-out upstream repository and each `*_PYTHON` to
that project's own isolated interpreter. When `*_PYTHON` is configured without
an `*_ENTRYPOINT` or `*_MODULE`, OpenKitty selects the bundled shim
automatically. Use an absolute `*_ENTRYPOINT` only for a separately reviewed
override. Do not share one venv between the three upstream projects.

For the bundled FinGPT/MiniMax integration, set
`QUANT_TRADER_FINGPT_CALLABLE=fingpt_minimax_callable:analyze` and allowlist
only `QUANT_TRADER_FINGPT_CALLABLE,MINIMAX_API_KEY,MINIMAX_BASE_URL,MINIMAX_MODEL`.
Their values come from the correspondingly scoped
`QUANT_TRADER_MINIMAX_API_KEY`, `QUANT_TRADER_MINIMAX_BASE_URL`, and
`QUANT_TRADER_MINIMAX_MODEL` variables. Keep real values outside source
control and test reports.

Example FinGPT callable contract:

```python
def analyze(request):
    assert request["safety"]["live_trading"] is False
    return {
        "status": "success",
        "output": "model-derived analysis",
        "data": {"score": 0.2},
        "warnings": [],
        "artifacts": [],
    }
```

Run the stdlib tests from this directory:

```powershell
python -m unittest discover -s tests -v
```
